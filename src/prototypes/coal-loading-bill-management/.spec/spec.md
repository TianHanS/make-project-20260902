# 上煤单管理

> 从燃料集控设计工程复制的可运行原型。目录：`src/prototypes/coal-loading-bill-management`。

## 📋 功能说明

### 1.1 核心目标
> 简要说明该功能的核心定位、解决的问题、用户场景

为燃料运行人员提供上煤单的查询、查看、煤量调整与确认。系统按当前入炉班次定时汇总各入厂批次煤量；班次结束后统计固化，人工可调出、删除已明确批次或把未识别煤量分配到入厂批次，操作即保存。确认后上传 MIS 并更新煤堆库存。

### 1.2 使用角色
> 列出此功能模块使用的主要用户对象

- **运行值班员**：查询上煤单、查看明细
- **确认人员**：班次结束后确认上煤单并提交 MIS
- **燃料管理人员**：追溯班次上煤留档与确认记录

## 📊 业务规则/约束

### 2.1 业务规则

1. **数据统计更新逻辑**
   - 系统按当前入炉班次定时汇总各入厂批次煤量。当前班次没有上煤单时，按「日期 + 班次」生成批次号，取班次开始时间作为上煤时间，状态为未确认。
   - 班次进行中，汇总结果持续被定时统计更新，只可查看，不可调整、不可确认。
   - 班次结束后统计固化。此后只允许在已分配批次与未识别煤量之间划转，上煤总量不变。
   - 人工保存后，以人工调整结果为准，定时汇总不再覆盖该单。原型不提供「统计数据刷新」。
   - 按煤仓统计保持系统结果，只读，不随批次划转改写。

2. **上煤单列表**
   - 默认查询近三日统计数据，按上煤日期逆序返回。
   - 查询条件：上煤日期（默认近三日）、批次号模糊匹配、确认人模糊匹配。
   - 表头操作：筛选（展开/收起高级筛选区）。

3. **列表操作**
   - **查看**：打开右侧抽屉，只读展示上煤单与两份统计。
   - **确认**：已确认单据不展示；班次未结束时禁用。打开「确认入炉批次」抽屉，可划转煤量。列表不提供「调整」。调出、分配、删除确定后立即保存。抽屉内「提交确认」保持可点；若仍有未分配煤量，点击后消息提示，不出现二次确认。未分配煤量为 0 时，按钮旁气泡确认，文案为「是否确认，确认后，上煤单将自动上传 MIS，对应班次上煤明细将禁止再次维护！」。确认后上传 MIS、锁定明细并扣减煤堆库存。

4. **上煤单表单**
   - 上煤时间、班次、批次号、状态、上煤总量(t)：只读。状态为「待确认」或「已确认」。上煤单没有描述字段。上煤总量在调整过程中保持锁定。
   - 抽屉内不展示定时汇总、固化、禁止确认等规则说明。
   - 页签为「按批次统计」「按煤仓统计」。没有「统计数据刷新」。
   - 按煤仓统计按煤场、分区排序。字段：序号、机组、煤仓、煤场、分区、煤种、SAP煤种、实际上煤量(t)。煤种与 SAP煤种留空。
   - 按批次统计字段：入厂登记编号、车船号、库存煤种、煤品种、煤种、实际上煤量t、占比。占比相对本单上煤总量。车船号来自入厂批次，未识别批次该列为空。
   - 未识别批次固定在最后一行，入厂登记编号列显示「未识别批次」。其下按煤场只读列出输煤计算结果中的未识别煤量，字段为煤场、未识别煤量t。用户据此把未识别总量分配到入厂批次，煤场明细本身不可改。
   - 班次已结束且未确认时，仅有入厂登记编号的行展示「调出」「删除」；仅未识别批次行展示「分配」。煤量单元格不可直接修改。
   - **调出**：右侧抽屉加载当前批次与当前煤量。调出类型为单选，选项为退回未识别、划入其他批次，默认划入其他批次。调出煤量为步进器，不可大于该批次当前煤量。划入其他批次时需选目标批次：下拉只列当前按批次统计中的其他批次，展示批次编码、车船号、库存煤种。选项不够时点「更多批次」，进入二级抽屉，按入厂登记编号选择目标批次。确定后立即保存并更新本班次统计；目标批次已存在则累加。
   - **删除**：气泡二次确认。确认后删除该行，煤量计入未识别批次，并立即保存。
   - **分配**：右侧抽屉加载未识别总量，以列表一次分摊到多个目标批次。每行选择目标批次并录入分配煤量，可添加、删除行。「均分煤量」把未识别总量平均分到当前各行，尾差计入最后一行。目标批次下拉只列当前统计中尚未选过的批次，展示批次编码、车船号、库存煤种；不够时该行点「更多批次」选择入厂登记编号。各行煤量合计不可超过未识别总量，同一批次不可重复。确定后立即保存；目标批次已存在则累加，未分摊完的煤量仍留在未识别批次。
   - 表下展示已分配、未识别、上煤总量。已分配 + 未识别 = 上煤总量。
   - 「还原批次分配」只在按批次统计中、合计下方展示。批次分配与原始输煤程控计算结果不一致时可点。按钮旁气泡确认，文案为「根据出库明细重新统计数据，还原后，现有人工调整结果会被清除，确认还原？」。确认后按原始输煤程控计算结果重算本班次按批次分配，清除人工调整结果，不改按煤场的未识别明细。
   - 「提交确认」保持可点。仍有未分配煤量时消息提示；未分配煤量为 0 时以气泡二次确认。不使用抽屉做二次确认。

### 2.2 操作说明

- **数据类型**：上煤单列表、上煤单主表、上煤明细
- **数据源**：前端 Mock（模拟定时汇总、人工调整、MIS 上传、煤堆扣减）
- **关键操作**：
  - `查询`：按上煤日期、批次号、确认人过滤
  - `筛选`：展开/收起筛选面板
  - `查看`：右侧抽屉只读展示表单与两份统计
  - `确认`：班次结束后打开可编辑抽屉，调出、删除已明确批次，或分配未识别煤量
  - `调出`：确定后立即保存。默认划入其他批次，目标批次可从当前统计或更多批次中选择
  - `删除`：气泡确认后把该批次煤量计入未识别批次
  - `分配`：列表一次分摊到多个批次，合计不超过未识别总量，确定后立即保存
  - `还原批次分配`：气泡确认后按原始输煤程控计算结果重算批次分配，清除人工调整结果
  - `提交确认`：按钮保持可用。仍有未分配煤量时消息提示；未分配煤量为 0 时气泡确认，提交 MIS 并更新状态

### 2.3 界面默认情况
> 说明功能模块默认情况如何展示、加载

- 整体风格参照「卸煤计划管理」：浅色工业后台、浅蓝表头、斑马纹表格、橙色未确认状态标签。
- 默认加载近三日上煤单，按上煤日期倒序。
- 「查看」「确认」均采用右侧抽屉。列表没有「调整」。抽屉右上角提供「提交确认」；「还原批次分配」只在按批次统计合计下方。调出、分配使用抽屉；删除、还原、提交确认的二次确认使用气泡。目标批次不够时，「更多批次」再开一层抽屉。没有「保存统计数据」「统计数据刷新」，也没有输煤计算结果确认页。
