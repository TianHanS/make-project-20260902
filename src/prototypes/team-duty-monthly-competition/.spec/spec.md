# 班值月度竞赛统计（燃运小指标竞赛）

> 从燃料集控设计工程复制。目录：`src/prototypes/team-duty-monthly-competition`。明细查询跳转本工程内的燃运值班报表。

## 📋 功能说明

### 1.1 核心目标
基于「燃运班值报表」月度汇总数据，对各班值（发电一值～发电四值）的卸煤量、加仓量、卸煤/上煤效率、设备综合投用率、卸煤段/上煤段输煤单耗、卸煤段/上煤段皮带空载率共 **9 项小指标** 进行极差标准化打分与加权综合排名，支持月度查询、权重字典维护与竞赛报表导出，促进班值间相互比拼、提升燃运作业效率。

> 本原型对应需求编号 **4.6.5 AD6.3**，为**独立新页面**，不修改既有「燃运班值小指标竞赛统计」原型。

### 1.2 使用角色
- **值班长/班组长**：查看当月本班综合排名与单项得分，定位薄弱指标
- **燃运主管/专工**：月度绩效考核依据；维护指标权重字典
- **厂级管理人员**：查阅班值竞赛态势与导出归档

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 统计调度（约束）
1. 每日 **00:05** 定时统计计算「前一日所在月份」各班值得分；排名数据日过后刷新
2. 计算顺序：先算各班值月度业务指标 → 再算单项分数 → 最后算综合得分
3. **仅对当前月度有效**：不更新历史已固化的月度竞赛报表

#### B. 指标计算（来源：燃运班值报表）
| 指标 | 方向 | 计算规则 |
|------|------|----------|
| 卸煤量 t/班 | 正向 | 月度内该班值所有卸煤量累加 |
| 加仓量 t/班 | 正向 | 月度内该班值所有加仓量累加 |
| 卸煤效率 t/h | 正向 | 月度内该班值各班次卸煤效率求平均 |
| 上煤效率 t/h | 正向 | 月度内该班值各班次加仓效率（上煤效率）求平均 |
| 设备综合投用率 % | 正向 | 入厂采样、入炉采样、除铁、除尘等投运率累加后求平均 |
| 卸煤段输煤单耗 t/kWh | 正向 | 月度内卸煤段输煤单耗求平均 |
| 上煤段输煤单耗 t/kWh | 正向 | 月度内上煤段输煤单耗求平均 |
| 卸煤段皮带空载率 % | 逆向 | 月度内卸煤段空载率求平均 |
| 上煤段皮带空载率 % | 逆向 | 月度内上煤段空载率求平均 |

#### C. 单项得分（保留 2 位小数）
- 正向：`[(班组值 - 极小值) / (极大值 - 极小值)] × 100`
- 逆向：`[(极大值 - 班组值) / (极大值 - 极小值)] × 100`
- 当极大值 = 极小值时，该项得分记为 `100.00`

#### D. 综合得分（保留 2 位小数）
`Σ(单项得分_i × 权重_i)`，权重取自字典 `teamdutyCompetition`（小数形式，如 0.12）

#### E. 权重字典（`teamdutyCompetition`）
本功能单独提供编辑弹窗，字段均为整数（单位 %），保存按小数入库：
1. 卸煤量权重 2. 加仓量权重 3. 卸煤效率权重 4. 上煤效率权重  
5. 设备综合投用率权重 6. 卸煤段输煤单耗权重 7. 上煤段输煤单耗权重  
8. 卸煤段空载率权重 9. 上煤段空载率权重  
保存校验：前后端权重累加须为 **100（%）/ 1.00（小数）**，并记录更新人。

#### F. 数据对象（字段对齐）
- 主表：`gxsz_statistics_teamduty_competition_report`（月度、班值、排名、综合得分、9 指标值/得分/权重快照）
- 权重表：`gxsz_statistics_teamduty_competition_weight`（指标编码、权重、正逆向、更新人）

### 2.2 操作说明

- **数据类型**：月度竞赛排名报表 + 权重字典配置
- **数据源**：基于燃运班值报表聚合生成的示例数据（当前月可随权重重算；历史月固化只读）
- **关键操作**：
  - `查询`：按统计月份筛选竞赛主表
  - `重置`：恢复默认月份（当前演示月）
  - `导出`：二次确认后导出当前查询结果 CSV
  - `权重设置`：打开权重编辑弹窗；各指标权重为整数（%），合计须为 100；展示更新人与更新时间；保存后对当前月重算得分与排名
  - `表头排序`：支持按排名、综合得分及各指标列排序
  - `明细查询`：跳转「燃运值班报表」，自动带入该班值名称及当前统计月份起止日期，展示对应班值值班明细

### 2.3 界面默认情况
- 默认统计月份：当前演示月（2026-07）
- 默认按综合得分降序 / 排名升序展示四个班值
- 权重弹窗仅展示用户需配置的权重项与更新信息，不展示字典编码、正逆向标签及内部落库说明
- 主题：项目默认 `antd-new` 浅色中后台
