# 自动入厂监测

## 📋 功能说明

### 1.1 核心目标

面向入厂口值班管理员，监测 A/B 系统下各入厂点的设备状态、运行日志与入厂登记记录。

- **A 系统**：入厂点 1#、2#
- **B 系统**：入厂点 3#、4#
- 同一系统内 **两个入厂点上下排列**，按点名顺序（1# 在上、2# 在下，或 3# / 4#）
- 页内不包含系统框架层标题/面包屑，仅保留 A/B 系统切换

### 1.2 入厂点行布局（从左至右三栏）

每个入厂点为一行卡片，内部三列：

| 列 | 内容 |
|----|------|
| **1. 设备监测** | 车号识别、LED 在线/离线状态；车号识别实时监控画面；LED 下发文案条幅 |
| **2. 运行日志** | 自动入厂启用/停用开关（**Popconfirm 气泡二次确认**）；运行日志列表（支持全部/正常/异常筛选） |
| **3. 入厂登记记录** | 本入厂点入厂登记记录表格，**按入厂时间逆序** |

## 📊 业务规则

- 启停自动入厂：点击开关弹出气泡确认，确认后生效并写入日志
- 日志异常行红底红字凸显
- 设备离线或停用服务时，监控画面显示遮罩说明

```
────────────────────────────────────────
入厂点 1#

────────────────────────────────────────
入厂点 2#
[ 设备监测 | 运行日志 | 入厂登记记录 ]
```

## 🎨 视觉规范

- 浅色 Ant Design 后台（`antd-new`）
- 三列等分网格，列间竖线分隔
- **入厂点卡片固定高度**（`400px`），上下两张卡片等高不随内容撑开
- **运行日志、入厂登记记录**在卡片内局部滚动，表头/工具区固定
- 设备状态：**小圆点（绿=在线、灰=离线）+ 设备名称**，横向排列
- 窄屏下三列改为上下堆叠，卡片改为最小高度约束
