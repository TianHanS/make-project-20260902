自动入厂流程配置（场景表单）已确认

本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并简短记录会影响当前原型的重要用户决策和变更。主规格已确认，实现需与本文双向同步。

当前方案

  • 原型意图：自动化配置中完成 AER 自动入厂与 WBM 汽车衡无人值守计量配置。WBM 遵循「设备布局及计量要求 → 自动匹配流程/参数 → 编排微调 / 高级」。
  • 使用场景：现场实施人员配置入厂登记流程，或通过设备布局及计量要求生成汽车计量流程与默认参数后微调。
  • 当前表达：列表含分类 Tab。AER：双 Tab 表单。WBM：同一抽屉三 Tab，依次为设备布局及计量要求（确认重编排 / 仅保存布局）、流程编排（子流程库）、高级参数配置（按子流程块 + 非流程参数）。

事实与输入

用户确认事实

  • 模块类型：AER 自动入厂；WBM 汽车计量。
  • 卡片可用操作：与已上线一致，仅展示控制设置、流程配置；流程复制本期注释隐藏。流程是否已维护通过「流程配置」按钮状态表达：未维护显示小红点（AER / WBM 均适用）。
  • 原型落点：目录 auto-entry-config-form（扩展 WBM，不另起原型）。
  • WBM：「设备布局及计量要求」是抽屉内第一个 Tab，不再是独立抽屉或 Tab 栏右侧入口。打开抽屉一律默认落在该 Tab（无论是否已配置）；未配置时其余两个 Tab 置灰不可进；「保存并重新设定」后自动匹配执行流程与参数并跳到流程编排；仅「保存」留在本 Tab。保存引起配置回流时保留用户当前所在 Tab。抽屉底栏是唯一一级操作区：布局 Tab 上为「关闭 / 保存 / 保存并重新设定」，另两个 Tab 上为「关闭 / 保存」，Tab 内不再单独放操作行。
  • WBM 流程编排：子流程库分类复选 + 可重复加入 + 拖拽/调序；保存编排重载默认参数。必选子流程（含「计量抓拍」）在执行流程中不显示删除按钮，禁止删除；可选子流程点删除即移除。
  • WBM 默认编排（「保存并重新设定」按计量流程生成）：
    • 先识别再上磅：计量前 车辆识别及核验 → 空磅核验 → [来车道闸抬杆] → 已上磅判断 → [车辆二次核验] → 车辆稳定（熄火）核验 → [司机下车核验]；计量中 重量取值 → 计量抓拍 → 计量数据上传；计量完成 [磅单打印] → [对向道闸抬杆] → [车辆已下磅核验] → 设备复位。
    • 先上磅再识别：计量前 车辆识别及核验 → 已上磅判断 → [车辆二次核验] → 车辆稳定（熄火）核验 → [司机下车核验]（不含空磅核验、来车道闸抬杆）；计量中 / 计量完成与上相同。
    • 条件插入：二次核验←一致性校验=是；司机下车←要求下车=是；来车抬杆←进厂方向有道闸；对向抬杆与已下磅←出厂方向有道闸；磅单←磅单打印勾选派生为是。带 * 的为必选子流程。
  • WBM 执行流程按 Excel【2.1】分「计量前 / 计量中 / 计量完成」三个大类分框展示，框头显示本类步数；设备控制类子流程不单独成框，来车道闸抬杆 / 落杆默认落计量前、对向道闸抬杆 / 落杆默认落计量完成。步序号全局连续（1…N），跨框累计。
    • 强制归属父级分类（Excel E 列＝是）：车辆识别及核验、已上磅判断、车辆二次核验、车辆稳定（熄火）核验、司机下车核验、重量取值、计量超量程及处理、计量数据上传、磅单打印、车辆已下磅核验、设备复位只能在本大类内调序，拖到其他大类时拒绝并提示「「XX」只能在「计量前 / 计量中 / 计量完成」内调整」。
    • 可跨类（E 列非「是」）：空磅核验、计量抓拍、来车道闸抬杆、来车道闸落杆、对向道闸抬杆、对向道闸落杆可拖到任意大类。
    • 强制排序（Excel F 列）：计量前 车辆识别及核验 1 → 已上磅判断 2 → 车辆稳定（熄火）核验 3；计量中 重量取值 1 → 计量数据上传 2。带号子流程在本类内不可互相逆序，号之间允许插入其他子流程；违规拖拽拒绝并提示「「A」需排在「B」之前」。带号子流程卡片上显示「顺序 N」标记。
    • 从子流程库添加：落入该子流程默认大类，带强制排序号的按号找位次（插到第一个更大号之前），无号的落该大类末尾。
    • 拖拽落位支持两种目标：落在某个子流程上＝插到它前面；落在框空白处＝落到该大类末尾；被拒绝时不改动执行流。
    • 颜色口径：大类框标题色与右上角图例严格一一对应——计量前 #1677ff、计量中 #13c2c2、计量完成 #52c41a、设备控制 #fa8c16；步骤卡片左侧色条按子流程分类取同一套色值。
    • 变更标记：以上次保存（或上次重新匹配）的执行流程为基线，新增步骤整行紫底 + 紫色序号 + 「新增」标签，调序步骤整行品红底 + 品红序号 + 「调序 · 原第 N 步」标签（紫 #722ed1 / 品红 #eb2f96 避开图例四色，左侧分类色条不被覆盖）；调序判定用最长递增子序列比对，只标真正挪动位置或换了大类的步骤，插入一步不会把后面整批标成变动。执行流程标题右侧同步给「新增 N 步 / 调序 M 步」汇总，未保存时注「保存后生效」。
  • WBM 高级参数配置左侧时间轴按同样三个大类分段，段首显示「计量前 / 计量中 / 计量完成」小标题，序号与流程编排一致。
  • 设备布局按「进厂方向 / 出厂方向」表述（原「来车方向 / 来车对向」）。布局下设「是否单向过磅」：重衡、轻衡默认开启，重衡只加载进厂方向、轻衡只加载出厂方向；混用衡、可切换衡默认关闭并同时加载两个方向。开关切换会清空/回填被隐藏方向的设备关联。
  • 车牌识别器（向外 / 向内）与读卡器在下拉右侧各带「主设备 / 辅助设备」单选：未选设备时置灰不可选，选定设备后可切换。默认向外车牌识别器为主设备，向内车牌识别器与读卡器为辅助设备。设备布局卡片说明：选择主要识别设备，若主设备异常，则根据辅助设备识别来车；主辅设备都正常时，使用主辅设备相互验证。原型不限制每个方向只能有一个主设备。
  • 场景业务要求固定展示「进厂方向抓拍摄像头」「出厂方向抓拍摄像头」两个单选下拉（可「不关联」），不随衡器类型或「是否单向过磅」隐藏；两方向摄像头互斥占用。方向设备布局区不再放置抓拍摄像头。
  • 场景业务要求：「是否磅单打印」去掉开关，直接按已勾选计量车种加载对应磅单打印选项，多选、默认都不选，是否编排「磅单打印」子流程由勾选结果派生。
  • 设备布局及计量要求 Tab 有未保存改动时禁止切到其他 Tab，提示「需保存已改动参数」。
  • 子流程库不含「车辆停放位置核验」与「异常放行控制」：前者的红外对射次数/间隔与前后限位提示移到「非流程参数配置」的独立卡片；后者与非流程「异常结束放行」重复，只保留非流程配置。
  • WBM 无独立「基础参数」Tab：设备布局及计量要求即为基础配置；高级参数按子流程分块，左侧纵向时间轴导航；顶栏固定（仅参数/仅消息互斥筛选 +「非流程参数配置」）；非流程参数二级抽屉对齐 Excel【2.4】，但不含「自动卸煤」（该项已去掉）；「动态切换模式」拆成两个参数：「是否启用模式切换」（参数 10065，单选启用 / 不启用，默认不启用）与「支持模式」（多选重衡 / 轻衡 / 混用衡，默认重衡 + 轻衡），启用后才展开支持模式与各切换道闸、LED、默认模式参数；道闸参数按衡器类型分成「切换重衡时 / 切换轻衡时 / 切换混用衡时」三个子块，只显示「支持模式」已勾选类型对应的子块，「默认切换模式」的可选项同样收敛为已勾选类型；消息通知与 AER 一致（占位符 + 发送测试）。
  • AER：打开流程配置直接进入双 Tab 表单并加载固定默认项；已有配置则回填。
  • 配置表单：基础参数 / 高级参数 两个 Tab；同源字段标记「基础参数」标签。
  • 消息通知：截图式卡片网格；广播 / LED 分通道启用与内容；支持占位符插入。
  • 表单 Tab 固定在抽屉内容区顶部，不随下方参数区滚动。
  • 设计基底：延续 Ant Design 后台浅色；主规格载体 HTML。

当前假设

  • 模块已有已保存配置时：打开流程配置直接进入表单并回填。
  • 选择「标准自动入厂」：写入场景默认值后进入表单（可再改）。
  • 「自定义配置」：进入表单，基础字段用通用默认值（是否含固废=禁用；入厂点未选）。
  • 关联入厂点名：下拉单选入厂点名称；查询结果仅 1 个时自动赋值；保存前必填。
  • 是否含固废：开关，默认禁用（0）；启用=1；已替代原「登记类型」参数。
  • 固废请求IP端口：仅「是否含固废」启用时显示并必填；占位提示「如 192.168.92.1:81」。
  • 来煤、非煤登记通知默认展示；固废登记通知随「是否含固废」显隐。
  • 复制流程：同类型 AER、排除自身、二次确认、覆盖目标配置（含场景来源标记）。
  • 非 AER / 非 WBM 卡片：控制设置 / 流程配置静态占位。
  • 鉴权、真实接口、设备联调、点表、自动卸煤审批、控制操作真实面板不在本期。

原型范围

本次呈现

  • 自动化配置卡片列表（筛选、分页、AER / WBM 与若干其他类型 mock）。
  • AER：流程配置右侧抽屉（双 Tab 表单）。
  • WBM：单个流程配置抽屉三 Tab（设备布局及计量要求 / 流程编排 / 高级参数）；校验可用，下发/联调占位。
  • 控制操作占位提示。

本次不呈现

  • 自由编排子流程库、快速配置多模板、全局参数独立抽屉（属旧原型能力）。
  • 控制操作真实表单；多场景包（除标准自动入厂外）。
  • 真实后端 / 设备联调 / 其他模块类型完整配置；WBM 重轻衡切换全量联调。

验收重点

  • AER / WBM 卡片两按钮「控制设置 / 流程配置」在卡片底栏同一行展示；控制设置为占位。顶栏业务分类 Tab：全部 / 出入厂 / 计量 / 机械采样 / 皮带采样。未维护流程配置显示小红点。
  • WBM：空配置打开落在第一个 Tab「设备布局及计量要求」→ 保存并重新设定 → 自动跳到流程编排 / 高级参数 → 保存；「保存」布局仅存场景不影响流程，且留在当前 Tab。
  • AER：空配置打开直接进入双 Tab 表单并加载固定默认项。
  • 基础 / 高级同源字段以「基础参数」标签标识。
  • 高级 Tab：左侧「入厂流程」导航 + 右侧各步蓝色统一卡片配参（保留顺序编号）；步骤不可增删排序；消息占位符 `{…}` 删除时整段移除。对标现有系统左侧导航交互。
  • 通知项为截图式消息通知配置（广播启用+内容、LED启用+内容 + 占位符）；道闸控制含「无」；复位含复位消息设定；复位等待默认 15s；道闸复位默认「无」。
  • 复制到同类型其他模块，二次确认后覆盖并提示。

场景说明进入表单后的默认

表单参数方案

基础参数 Tab

流程运行必须参数。

参数控件选项 / 默认说明
*是否含固废 开关 1 启用；0 禁用（默认） 替代原登记类型；与高级 Tab 双向同步；启用后展示固废请求IP端口及固废通知

高级参数 Tab

Tab 旁小图标，悬停提示：如需改动更多流程信息、各环节消息通知内容，可按入厂登记子流程调整对应参数以达到需要的流程效果。

进入后左侧为「入厂流程」导航（01 车辆识别 → 02 登记 → 03 道闸控制 → 04 现场复位还原），右侧按步展示可配参数；点击左侧项滚动并高亮对应区块，右侧滚动时左侧选中态同步。

消息通知：提示「每组可分别设定广播 / LED 是否启用及推送内容；未启用或内容为空则不推送该通道」；各结果通知卡片可「发送测试」（仅已启用且内容非空的通道），变量以「— —」占位；顶部可插入占位符（含换行符号 {/n/}）。

设计基底与原型特有调整

  • 采用设计基底：延续参考原型 auto-entry-config 的 Ant Design 后台浅色（无独立 theme 包，原型内 CSS tokens）。
  • 关键 tokens：主色 #1677ff、布局背景 #f0f2f5、卡片白底、边框 #f0f0f0 / #d9d9d9、圆角 6–8px、控件高 32px。
  • 本原型特有调整：
    • 场景选择：抽屉内卡片支持单选勾选与「选择」按钮，底部可「进入配置」（非二级弹层）。
    • 高级参数：左侧入厂流程导航 + 右侧配参区块。
    • 共享字段：两 Tab 可编且同步，标签「基础参数」标识同源字段。
    • 通知：截图式消息通知卡片；广播/LED 各自启用开关 + 内容行内排布 + 占位符插入；未启用或空内容不推送。
    • AER 操作区三按钮同一行完整展示，控制操作为占位。
    • 表单抽屉约 1040px；参数网格一行 2–3 列；Tab 吸顶不随内容滚动。
