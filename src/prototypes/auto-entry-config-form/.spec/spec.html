  • 原型意图：新建独立原型，在沿用自动化配置列表骨架的前提下，用「场景选择 → 基础/高级双 Tab 表单」重做 AER（自动入厂）流程配置体验。
  • 使用场景：现场实施人员在模块卡片上配置 / 复制自动入厂流程；标准化方案与现场不一致时可走自定义配置。
  • 当前表达：列表页与参考原型 auto-entry-config 基本一致；流程配置为右侧抽屉（先场景或直接表单）；表单固定入厂登记四步链路，不做自由子流程编排。旧版 auto-entry-config 保留对照，不覆盖。

当前假设

  • 模块已有已保存配置时：打开流程配置直接进入表单并回填，可从顶栏「重选场景」回到场景列表。
  • 选择「标准自动入厂」：写入场景默认值后进入表单（可再改）。
  • 「自定义配置」：进入表单，基础字段用通用默认值（登记类型=来煤、非煤物资；入厂点待选）。
  • 关联入厂点名：下拉单选，mock 若干入厂点；保存前必填。
  • 登记类型切换时：高级 Tab 中与类型相关的通知项按适用性显隐（来煤/非煤组 vs 固废组）；「自动登记」时两组均可配。
  • 复制流程：同类型 AER、排除自身、二次确认、覆盖目标配置（含场景来源标记）。
  • 非 AER 卡片：控制设置 / 流程配置静态占位，提示本原型仅演示 AER。
  • 鉴权、真实接口、设备联调、控制操作真实面板不在本期。

原型范围

本次呈现

  • 自动化配置卡片列表（筛选、分页、AER 与若干其他类型 mock）。
  • AER：流程配置右侧抽屉（场景选择层 + 双 Tab 表单层）。
  • 复制流程抽屉 + 二次确认。
  • 控制操作占位提示。

本次不呈现

  • 自由编排子流程库、快速配置多模板、全局参数独立抽屉（属旧原型能力）。
  • 控制操作真实表单；多场景包（除标准自动入厂外）。
  • 真实后端 / 设备联调 / 其他模块类型完整配置。

验收重点

  • AER 卡片可见三按钮：流程配置、复制流程、控制操作；控制操作为占位提示。
  • 空配置打开：先场景列表（标准自动入厂 + 自定义）；选后进入双 Tab 表单。
  • 基础 / 高级中登记类型与入厂点双向同步；高级 Tab 有同步提示文案。
  • 高级 Tab：横向四步流程 + 各步配参；步骤不可增删排序。
  • 通知项为开关 + 文案；放行道闸含「无」；复位等待默认 15s；道闸复位默认「无」。
  • 复制到同类型其他模块，二次确认后覆盖并提示。

场景

场景说明进入表单后的默认
标准自动入厂 根据读取的车辆信息，自动进行来煤、非煤入厂登记，并放行抬杆 登记类型=来煤、非煤物资；道闸控制=抬杆；复位等待=15；道闸复位=无；通知文案按标准预制
自定义配置 标准化方案与目标不一致时自行配参 登记类型默认来煤、非煤物资；入厂点空；其余用同套通用默认，不强制绑定场景说明文案

表单参数方案

基础参数 Tab

流程运行必须参数。

参数控件选项 / 默认说明
*登记类型 下拉单选 1 来煤、非煤物资（默认）；2 固废粉煤灰；3 自动登记 与高级 Tab 同名字段双向同步
*关联入厂点名 下拉单选 mock 入厂点列表；无默认必选 与高级 Tab 双向同步；保存必填

高级参数 Tab

Tab 旁小图标，悬停提示：如需改动更多流程信息、各环节消息通知内容，可按入厂登记子流程调整对应参数以达到需要的流程效果。

进入后顶部展示横向流程图提示：车辆识别 → 登记 → 车辆放行 → 现场复位还原。下方按步展示可配参数（点击节点可滚动/高亮对应区块）。

1. 车辆识别

参数控件默认假设
车辆识别信息通知 启用开关 + 文案 启用；文案如「请上磅识别」

2. 登记

参数控件选项 / 默认说明
*登记类型 下拉单选 同基础 Tab 旁注「与基础参数同步」
*关联入厂点名 下拉单选 同基础 Tab 旁注「与基础参数同步」
来煤、非煤登记成功通知 开关 + 文案 启用；成功类默认文案 登记类型为固废粉煤灰时可隐藏或禁用
来煤、非煤登记失败通知 开关 + 文案 启用；失败类默认文案 同上
固废登记成功通知 开关 + 文案 启用 登记类型为来煤、非煤时可隐藏或禁用
固废登记失败通知 开关 + 文案 启用 同上

3. 车辆放行

参数控件选项 / 默认说明
道闸控制 单选 1 抬杆（默认）；2 落杆；3 无 本环节对道闸的动作

4. 现场还原复位

参数控件选项 / 默认说明
复位等待时长 s 整数输入 默认 15 前置登记结果在 LED 的通知保留多久后复位
道闸复位控制 单选 0 无（默认）；1 抬杆；2 落杆 放行后现场道闸可按此复位；雷达自动落杆则配「无」
