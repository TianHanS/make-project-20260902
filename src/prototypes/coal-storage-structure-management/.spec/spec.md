# 煤场存煤结构管理

> 自 `rljkDesgin` 迁入本项目的功能原型；目录：`src/prototypes/coal-storage-structure-management`。
> 三个煤场：**#1 / #2 圆形各 36 分区（每区 10°）**，**厂外中转煤场为条形 3 分区**。堆煤高度上限 20 m。界面不展示圆形方位示意图。

## 📋 功能说明

### 1.1 核心目标

面向燃料专责与盘煤专责，把「激光盘煤得到的分区体积」转化为「可追溯到入厂批次、煤种、煤质的分层存煤结构」，并提供出入库与分层维护的完整操作闭环。

解决五个具体问题：

1. **单煤场聚焦**：界面始终呈现单一煤场的库存存煤数据，通过下拉单选切换煤场。
2. **结构化**：按煤场 → 分区 → 分层维护。圆形煤场依扇形楔、条形煤场依直棱柱几何关系计算各分层体积与估算煤量，并按图形夹角与挡煤墙高度反算煤层分界的俯仰夹角。
3. **真实高度可读**：把 20 m 上限划分为 200 个 10 cm 分带，以热力图呈现各分区实际堆煤情况，使层厚与分区堆高差异可直接比对。
4. **自动化**：再次盘煤后按体积变动自动生成出入库——体积增加按周期内入厂批次做密度匹配，体积减少自上而下逐层扣减。
5. **人工维护**：入库（顶层新增煤层）、出库（后进先出）、分层拆分、合并上层/下层、删除表层，全部留痕。

### 1.2 使用角色

| 角色 | 主要任务 |
|------|---------|
| 燃料专责 | 标记未识别煤层、拆分与合并分层、手工出入库 |
| 盘煤数据 | 由第三方上传形成盘煤记录；本页只查询，不录入盘煤体积 |
| 集控值长 | 查看分区存煤结构与可取煤量、核对出入库明细 |
| 燃料调运 | 登记入库与出库 |

## 📊 业务规则/约束

### 2.1 业务规则

#### A. 煤场与分区

- 三个煤场均已启用。界面通过**下拉单选**切换，选项只加载已启用煤场，文案为煤场名称。进入页面时恢复上次离开时选中的煤场；切换时清空当前选中煤层：
  | 煤场 | 形态 | 分区 | 盘煤数据源 |
  |------|------|------|-----------|
  | #1 圆形煤场 | 圆形封闭，Φ130 m | 36 区（每区 10°） | 有 |
  | #2 圆形煤场 | 圆形封闭，Φ130 m | 36 区（每区 10°） | 有 |
  | 厂外中转煤场 | 条形，全场长 240 m、底宽 50 m | 3 区（每区 80 m） | 无 |
- 圆形煤场：内半径 8 m 为中心堆料塔，外半径 65 m 为挡煤墙，挡煤墙高 22 m。
- 条形煤场：斗轮沿轨道走行堆煤，挡煤墙高 18 m。
- 允许最大堆煤高度 **20 m**，燃煤安息角 38°。
- 界面一律按**分区编号增序**自左向右排列；**不展示圆形方位示意图**。

#### B. 几何模型

**圆形分区（扇形楔）**：径向断面是等腰梯形，沿周向张开 Δα。按 Pappus 定理：

```
V(h) = Δα · r̄ · A(h)
A(h) = h · (W − h/tanθ)      径向断面积，顶宽 = W − 2h/tanθ
r̄   = Ri + W/2               断面形心半径，W = Ro − Ri
```

**条形分区（直棱柱）**：同一径向断面沿分区长度 L 拉伸：

```
V(h) = L · A(h)
```

`V(h)` 在有效区间单调递增，故可由体积二分反解堆高。分区几何容量 = `V(20 m)`。

**俯仰夹角反算**：俯仰夹角 φ 是堆煤斜面相对场坪的图形夹角，与挡煤墙作业高度按正切比例换算。**0° 对应场坪 0 m，45° 对应 20 m 挡煤墙顶**；圆形场与条形场共用该关系：

```
tan(φ) / tan(45°) = h / 20
h = 20 · tan(φ)
φ = arctan(h / 20)
```

每层都有一段「起始角度（层底）~ 结束角度（层顶）」区间，取值落在 **0°～45°**。

分层体积按堆煤顺序自下而上累计：第 k 层体积 = `V(h_k) − V(h_{k−1})`。

#### C. 煤量与上限

- 煤量 = 体积 × 计算密度。平台默认密度 0.85 t/m³，作为系统 PUBLIC 分组参数 `DEFAUT_DENSITY` 保存。体积变动有效阈值默认 10 m³，作为系统 PUBLIC 分组参数 `VOLUME_LIMIT` 保存，只接受正整数：分区盘煤体积变动超出该阈值，才认为该分区存煤量发生变动。页头设置图标是这两项参数的维护入口，打开右侧抽屉「配置信息」（密度 0.8～1.2，保留 3 位小数）。入口按按钮权限展示。
- **各分区盘煤体积即该分区存煤煤量的上限**；层体积之和小于盘煤体积时，差额为「未分配体积」。
- 入库按所选分区均摊。超出分区堆煤高度或几何容量时只给出警告提示，不禁止提交。

#### D. 盘煤记录

本页不提供盘煤比对向导。盘煤记录由第三方上传，在页底「盘煤记录」中按当前煤场平铺列出。点「查看」打开抽屉看分区明细：本次体积、上次体积、变动量、是否引用更新库存。体积增加对应自动入库，体积减少对应自动出库；这两类不写入调整记录。

#1 圆形煤场的演示台账覆盖各类记录：入库、出库各有人工和盘煤自动；出库明细含全部扣减与部分扣减；调整记录覆盖更新煤层、标记入厂批次、拆分、合并上层、合并下层、清除。其中标记入厂批次是一条记录同时标记 5 区、6 区、7 区共 3 层；清除只有调整前快照。盘煤记录同时包含引用更新库存和未引用的分区。

「配备盘煤仪」和「自动根据体积更新库存」是煤场数据条件。未配备盘煤仪的煤场不显示实际堆煤视图，密度抽屉也不显示自动更新开关，煤层详情、分层数据、入库分区明细和台账分区明细都不展示层高、标高区间、起始/结束角度。开关默认关闭，只作用于当前煤场。

#### D2. 盘煤比对算法（本页未挂载）

1. 以**全煤场**为口径汇总新增体积 `ΣΔ⁺` 与周期内勾选入厂批次的卸煤量 `Σm`，匹配密度 `ρ = Σm / ΣΔ⁺`。
2. `ρ ∈ [0.78, 0.95] t/m³` → **自动识别**：各增量分区的新增体积按批次煤量比例拆分为煤层，按卸煤完成时间自下而上堆叠。
3. `ρ` 越界或周期内无可匹配批次 → **生成待标记煤层**：仅记录体积与按默认计算密度估算的煤量。
4. 体积减少的分区按减少体积**自上而下**逐层扣减，逐层按其入厂批次形成出库明细。
5. 圆形煤场按扇区连续作业，一个周期内通常只有少数扇区变动，故向导默认只列出有变动的分区，可一键展开全部 36 个。条形场仅 3 个分区，默认列出全部。

#### E. 未识别煤层

存在实际煤量体积但入厂批次归属不明的煤层，使用**固定异常红 `#cf1322`**，并叠加横向条纹纹理与「待标记」文案（颜色不作为唯一标识）。在实际堆煤视图、分层视图、分层数据、检视面板四处表现一致。检视面板顶部给出错误级提示，主按钮切换为 danger 态的「标记入厂批次」。

#### F. 操作 · 入库（顶层新增煤层）

- 抽屉标题为入库。必填：入厂登记编号、库存煤种、色值、入库煤量、计算密度。备注为文本。
- 入厂登记编号是表单里的一个只读输入框，点击后从来煤预报侧边抽屉选择。按预报时间倒序，单击行选中，双击即确认，可按登记编号、车船号、航次搜索。
- 预报回写且不可改的项直接显示：批次号、车船号、航次、煤品种、煤种；库存煤种已填写时同样直接显示，色值沿用该库存煤种已有色值。未填写时，库存煤种与色值并排出现，交互与来煤预报的煤种配置一致：可选择计划中已有库存煤种并带出其颜色，或输入新煤种，离开输入框后自动分配一个未占用色值。色值可再改，且不能与其他库存煤种重复。保存后把库存煤种回写该来煤预报；若改了已有煤种的色值，使用该煤种的煤层一起变色。
- 入库煤量保留 3 位小数，步进器输入，不接受负数和空格。计算密度默认取平台默认密度，可改。
- 选择入库分区是叠在入库抽屉上的侧边抽屉，列只含分区名称、存煤量、剩余容量。确认后回显到已选分区，煤量平均分摊，并计算分摊煤量、新增体积、俯仰角度范围、煤层高度范围。删除需再开一层确认抽屉，删除后重算。
- 本煤场已开启按体积自动更新时，表单内不常驻警告条。打开抽屉时给出一条消息提示：「本煤场按盘煤体积自动更新库存，手动入库会在下次盘煤后被覆盖。」确认时再打开侧边抽屉：「此煤场库存数据通过盘煤仪获得并自动更新，确认进行手动维护增加？」。
- 入库按分区、煤层写入库记录，处理方式为人工。

#### G. 操作 · 出库

- 出库分区必选，默认带入存煤结构里当前选中煤层所在分区。存煤量只读，随分区加载。
- 出库煤量保留 3 位小数，不接受空格和负数。失去焦点后，若超出该分区存煤量则提示异常，且不能确认出库。
- 存煤分层从表层往下排列：入厂登记编号、库存煤种、煤量、体积、预计扣减。层号从贴地底层起为 1，向上逐层递增。预计扣减从更高的煤层先出，标为全部扣减或部分扣减。
- 备注为文本。本煤场已开启按体积自动更新时，表单内不常驻警告条。打开抽屉时给出一条消息提示：「本煤场按盘煤体积自动更新库存，手动出库可能在下次盘煤后被覆盖。」
- 确认后按分区、每个被扣煤层各写一条出库明细，处理方式为人工。

#### G2. 出库确认

当前煤场已开启按体积自动更新时，以侧边抽屉确认，文案为：「此煤场库存数据通过盘煤仪获得并自动更新，确认进行手动维护增加？」

#### H. 操作 · 分层拆分

- 选中分层后展示该层的**煤量、体积、俯仰夹角区间与标高区间**。
- 下方分层信息列表按**自上而下**排列，上面的煤层排在前面。角度两列按起始角度、结束角度排列。子层标记从当前煤层的层序起往上递增：贴原层底的子层保留当前层序，其上方子层依次加 1。贴底子层的角度和入厂登记编号不可改。
- 可编辑子层的入厂登记编号点击后，在拆分抽屉上再开一层「选择来煤预报」抽屉，按预报时间逆序单选，交互与入库、标记入厂批次一致。留空表示该子层仍为待标记。贴底子层的编号只读。各子层已填的入厂登记编号不能重复。
- 角度联动：上一层的起始角等于下一层的结束角；最上层结束角锁定为原层顶角。
- 由系统锁定或联动得出的角度以浅底徽标标注来源（「锁定层顶」「取上层起始角」「锁定层底」），与可输入的起始角度形成明确区分。
- 输入框清空或处于中间态（如仅输入负号）时保留原值，不把 `null` 强制写成 0，避免数值被弹回。
- 校验：每行起始角度必须小于其结束角度且自上而下依次递减；分层体积必须大于 0。
- 分层数可增减（2~6 层），增减时按角度等分重置初值。
- **确认拆分需二次确认**，确认层为叠在拆分抽屉上的侧边抽屉。

#### I. 操作 · 分层合并

- **合并上层**：仅非顶层煤层可用；**合并下层**：仅非底层煤层可用。不可用时按钮禁用并在 `Tooltip` 中说明原因。
- 抽屉内并列展示两层煤的信息（煤层、入厂登记编号、煤种、体积、煤量、层厚、起始/结束角度），并用红色标签明确标记**被合并煤层**，该行整行浅红底。
- 合并后保留基准层的入厂批次归属，计算密度按两层体积加权重算，俯仰夹角区间按几何关系重新确定；两层批次不同时给出警告说明归属变化。

#### J. 操作 · 清除煤层

- **非表层煤不可直接删除**：按钮禁用，`Tooltip` 说明「其上方仍压覆着煤层，直接删除会使上层煤悬空。请先出库或合并处理表层煤。」
- 删除表层煤时以侧边抽屉二次确认，说明清除不会形成出入库记录，并列出该层的体积与煤量。
- 删除只写调整记录，不产生出入库记录。该条明细只有调整前快照。

### 2.2 操作说明

- **数据类型**：热力图 / 二维表格 + 操作抽屉 + 出入库台账。配置、填报、选择和二次确认全部使用右侧抽屉，不使用居中弹窗。
- **数据源**：前端生成（`data.ts`）。`/assets/database/` 下仅有 `orders.json`，与本业务无关，故按后台／ToB 场景生成专业、完整的兜底数据：2 个圆形煤场（各 36 区）+ 1 个条形煤场（3 区）、5 个煤种、12 个入厂批次，含预置未识别煤层。存煤分层按**作业带**生成：同一入厂批次覆盖连续分区并取相同层厚，相邻分区的同批煤层高度近似、色带连贯；未识别层也落在连续分区上。
- **入厂登记编号**格式沿用 `src/prototypes/coal-unloading-management` 的既有约定（如 `gxsz-2026-054RCDJ2026081802`）。

| `出库` | 分区默认取当前选中煤层；分层从表层往下列出，层号自贴地起为 1；扣减从更高煤层先出，一个煤层一条人工出库明细 | 失焦后煤量超出分区存煤量则不能确认 |
| `分层拆分` | 单层拆为 2~6 层。上面的煤层排在前面，子层号从当前层序往上递增。可编辑子层点击入厂登记编号后，在上一层抽屉选择来煤预报 | 角度须自上而下递减、各层体积 > 0；已填编号不能重复；需二次确认 |
| `合并上层 / 合并下层` | 相邻两层合并为一层 | 顶层禁用合并上层，底层禁用合并下层 |
| `删除煤层` | 直接删除表层煤，不形成出入库记录 | 非表层禁用；需二次确认 |
| `标记入厂批次` / `更改入厂批次与煤质` | 右侧抽屉填写。待标记煤层转为已标记，或改已标记层的批次与煤质；带入船名／航次／煤质，煤量按密度重算。单层标记时只读展示当前煤层所属煤场、分区、层数。更改已标记煤层时，入厂登记编号和库存煤种回显该层现有值。库存煤种与色值的选择与来煤预报煤种配置一致：已有煤种带出色值，新煤种自动分配未占用色值，色值可改且全局不重复。标记未识别煤层时，可多选分区批量标记其中的未识别煤层，或勾选「全部」一次标记本煤场所有未识别煤层。批量标记时不展示当前煤层的体积、煤量、船名、航次、热值、起止几何以及煤场、分区、层数，只录入入厂登记编号、库存煤种、色值、计算密度 | 入厂登记编号、库存煤种、色值、计算密度必填。来煤预报在上一层抽屉上再开一层抽屉选择 |
| `定位待标记煤层` | 跳选当前煤场第一个待标记煤层 | 无待标记时提示 |

### 2.3 界面默认情况

- 首次进入默认煤场 **#1 圆形煤场**；再次进入时加载上次离开时选中的煤场。默认视图 **实际堆煤视图**，默认展示信息 **库存煤种**，右侧检视面板为**空态引导**（含「定位 N 个待标记煤层」入口）。
- 页面不展示页面标题，也不展示与操作无关的读图注解。
- 页面自上而下三层结构，统计不单独占一行，主区域留给存煤结构视图：
  1. **页头**：煤场下拉单选；内联统计仅两项——存煤量、待人工标记（大于 0 时可点击定位）；右侧为设置图标，打开配置信息。当前煤场已开启按体积自动更新时展示状态标签。
  2. **存煤结构维护**：面板头含入库、出库按钮与视图切换；下方为展示信息筛选条、图例、视图区；右侧为常驻煤层信息面板。
  3. **页底台账**：入库记录、出库记录、调整记录、盘煤记录以 Tab 切换，表格平铺，默认每页 20 条。记录详情在右侧抽屉查看，不在列表中展开。
- 空状态：空区在实际堆煤视图中无方块；分层视图缺层格子用极淡斜纹表示。

## 🧭 布局与结构

- **布局模式**：单页纵向分区 + 主区双栏固定比例（内容区 `3.25fr` / 检视面板 `1fr`，检视最小 340 px，与主视图等高拉伸）。页面根节点 `min-width: 1280px`，窄屏横向滚动，**不把检视面板折到主视图下方**。
- **页头**：一条白底刻度栏，左缘煤蓝色标。煤场、存煤量、待人工标记、操作按钮同一行；栏内超出时横向滚动，按钮不被裁切。数字用 Bahnschrift / DIN 等宽。
- **页面底**：浅灰并叠极淡水平刻度线，衬托存煤结构视图。深度仍只用描边。
- **存煤结构维护 / 煤层信息**：工具条、展示信息筛选条、图例均为 `flex-wrap: nowrap`；内容超出时该条内部横向滚动，不随页面宽度自动换行。
- **实际堆煤视图**：全宽热力图，无左侧圆形示意图。圆形场 36 列用 34 px 窄列横向滚动；条形场 3 列用 196 px 宽列撑满主区。分带高 2.4 px（200 分带共 480 px），左轴堆煤高度每 2 m 一个刻度、右轴同高度对应的俯仰角度、底轴只显示分区编号（圆形场每 5 区加粗），不展示各分区堆煤高度。**左右纵轴 `position: sticky` 固定在滚动容器两侧**，横向滚动时始终可见，仅中间分区列与底轴随滚动条移动。
- **分层视图**：圆形场列宽最小 92 px、36 列横向滚动；条形场列宽最小 160 px、3 列均分。格内展示所选指标和煤量，底行只有各分区存煤量 t。
- **关键尺寸**：页面内边距 20/24 px；卡片圆角 8 px；间距基准 4 px。
- **表单文案**：入库、出库、拆分、合并、盘煤比对、标记批次、密度配置不展示计算过程说明（分摊方式、后进先出、俯仰角反算、匹配密度公式等）。标题只写动作名。校验失败、操作结果和字段本身保留。
- **响应式**：
  - 主区双栏比例在各宽度下保持不变，不因断点改单栏。
  - `≤ 1200px`：抽屉表单改两列。
  - `≤ 760px`：抽屉表单改单列；检视面板煤质仍保持五列。

### 设计意图与领域取色

设计意图：**白色浅色中后台**——干净、克制、有刻度。页面铬层对齐 antd-new 中性色；同一库存煤种使用同一颜色。

可视化域的煤层颜色与控件主色分工明确（控件表达“可操作”，可视化表达“煤场里的东西”）：

| 语义 token | 取值 | 来源与用途 |
|-----------|------|-----------|
| `--yard-apron` | `#f5f5f5` | 页面底色（antd 布局灰底） |
| `--yard-surface` / `--yard-inset` | `#ffffff` / `#fafafa` | 卡片与内凹底 |
| `--coal-ink` 四级 | `rgba(0,0,0,.88 / .65 / .45 / .25)` | 标题 / 正文 / 次要 / 禁用 |
| `--rule-hair/line/firm/focus` | `#f0f0f0` / `#e8e8e8` / `#d9d9d9` + 主色 | 四级分隔线 |
| `--scan-teal` | `#13c2c2` | 激光盘煤量测语义：体积增加、入库 |
| `--stacker-amber` | `#d48806` | 堆取料机语义：体积减少、出库 |
| `--unmarked-flare` | `#cf1322` | 未识别煤层的固定异常红 |

- **深度策略**：仅用描边（borders-only），不叠加阴影。
- **签名元素**：把 20 m 堆煤上限拆成 200 个 10 cm 方块的热力图，纵轴是真实标高、右轴是同一高度对应的俯仰夹角（0°～45° 对应 0～20 m 挡煤墙）——层厚直接表现为连续方块的段数。圆形场以 36 列展开图阅读周向结构，条形场以 3 列宽条阅读条段，均不再附圆形方位示意图。
- **拒绝的默认做法**：
  1. 固定行高的层序矩阵作为主视图 → 以真实标高为纵轴的 10 cm 分带热力图；
  2. 弹窗内改配置 → 右侧常驻检视面板 + 操作抽屉，操作时不丢失可视化上下文；
  3. 独立大数字 KPI 看板 → 页头只内联存煤量与待人工标记，纵向空间留给存煤结构视图。

### 配色规则

同一库存煤种使用同一颜色，不按入厂登记编号再分色阶。五个煤种各一种低饱和工业色（神混=蓝灰、准格尔=琥珀棕、印尼褐煤=褐红、俄罗斯煤=深青、蒙煤=紫灰）。入库和标记入厂批次在补库存煤种时可以改色或为新煤种选色，改色后该煤种的全部煤层同步。图例标注「颜色 = 库存煤种」。未识别煤层仍用固定异常红和条纹。

### 组件状态定义

| 状态 | 表现 |
|------|------|
| 默认 | 煤层方块填色 + 层顶分界线；卡片 1px 描边 |
| 悬停 | 煤层整层 `opacity .84`；格图内描 2px 白框（均无位移，不产生布局抖动） |
| 选中 | 煤层／格子 2px 主色描边 |
| 聚焦 | 煤层、格子均可 Tab 聚焦并显示主色外描边（`:focus-visible`） |
| 禁用 | 按钮 antd 禁用态 + `Tooltip` 说明禁用原因（而非静默禁用） |
| 加载 | 本原型为前端即时计算，无异步加载态；操作反馈统一用 `message` |
| 空 | 空区无方块；检视面板空态引导；表格 antd 空态 |
| 异常 | 待标记煤层：固定异常红 + 横向条纹 + `Tag` 文案 + 面板 error 级 `Alert`；校验失败用 `Alert` + 输入框 error 态并禁用提交 |

### 可访问性

- 煤层文字前景色按背景相对亮度自动在 `rgba(0,0,0,0.88)` / `#ffffff` 间切换，保证 WCAG 2.1 AA 对比度。
- 颜色不作为唯一标识：待标记煤层另有条纹纹理与「待标记」文案；分层视图格内除底色外还有层厚与标高区间数值。
- 煤层（热力图 `<g>`、格图单元）均可 Tab 聚焦，支持 Enter / Space 触发；热力图 SVG 带 `role="img"` 与中文 `aria-label`，每个煤层带 `<title>` 悬停摘要。
- `prefers-reduced-motion: reduce` 时关闭全部过渡动画；过渡时长统一 160 ms。
