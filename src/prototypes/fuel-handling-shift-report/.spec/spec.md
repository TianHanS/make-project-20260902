# 燃运班值报表设计规格

> 从燃料集控设计工程复制。目录：`src/prototypes/fuel-handling-shift-report`。支持从班值月度竞赛带入班值和日期。

## 📋 功能说明

### 1.1 核心目标
燃运班值报表是四维数字化煤场系统中的核心统计模块。其核心目标是自动化统计各发电值班期内的燃煤接卸、入炉加仓总量以及输煤、配煤关键设备的运行效能与用电指标。它能帮助电厂管理人员与值班长直观监控输煤系统的用能单耗、设备空载浪费情况、重载跳机异常以及采样/除铁/除尘等设备的综合投运率，为配煤调度与设备节能诊断提供客观的数据支撑。

### 1.2 使用角色
- **燃运值班长**：负责在每班结束时核对当班的接卸量、加仓量、设备运行时长与电耗，确保数据准确并导出归档。
- **燃运主管/专工**：监控月度/季度累计指标，分析输煤单耗趋势、空载率以及环保净化等设备的投用率，评估值班组绩效。
- **厂级管理人员**：全局查阅煤场运行日报和设备综合健康水平，进行节能降耗决策。

## 📊 业务规则/约束

### 2.1 业务规则
本原型完全实现以下数据指标统计计算规则与业务逻辑：

1. **接卸统计**：
   - **卸煤量（t）**：根据班值的起止时间，查询入厂皮带秤（BS下YCBSWeight）读数差值计算。白班与夜班各自累加其时间段内的净重差值。

2. **加仓统计**：
   - **加仓总量（t）**：取对应班值时间段内，入炉出库日志的累计总量数据。
   - **机组加仓量（t，分机组）**：按机组1（#1机组）、机组2（#2机组）聚合的煤仓加仓记录，白班与夜班分别统计，固定展示两台机组。

3. **输煤系统 - 卸煤段**（基于CTDCS-1程控DCS系统信号）：
   - **电度（kWh）**：累加该时段内对应的卸煤耗电量遥测信号点（Coal_Energy_Usage）。
   - **输煤单耗（t/kWh）**：计算公式为：`卸煤量 ÷ 卸煤段电度`。
   - **运行时长（min）**：根据卸煤段皮带运行信号（Unload_Belt_Run），当其判定为运行时累加时长。
   - **空载时长（min）**：当皮带系统处于运行状态，且所有有载信号（Unload_Belt_load）读数均小于10t时，判定为空载，累加对应时间。
   - **跳机次数（次）**：统计程控DCS在对应班值内发生过流/过载跳机保护信号的触发频次。**可点击**：打开该班次时间范围内卸煤段电流跳机报警记录明细。

4. **输煤系统 - 上煤段**：
   - **电度（kWh）**：累加该时段内对应的上煤耗电量遥测信号点（CTDCS_Part_Code_load_Coal_Energy_Usage）。
   - **输煤单耗（t/kWh）**：计算公式为：`上煤总量（加仓总量） ÷ 上煤段电度`。
   - **运行时长（min）**：根据上煤段皮带运行信号（CTDCS_Part_Code_load_Belt_Run），运行信号超过40%运行时判定为运行，累加得到。
   - **空载时长（min）**：当系统处于运行状态且有载信号（load_Belt_load）全部小于10t时判定为空载，累加得到。
   - **跳机次数（次）**：统计上煤段发生电流过大、过载等异常跳机的总次数。**可点击**：打开该班次时间范围内上煤段跳机报警记录明细。

5. **设备综合投运分析**：
   - **设备分类**：包含 **入厂采样**（In_Belt_Sample）、**入炉采样**（Load_Belt_sample）、**除铁装置**（Iron_Remove）、**除尘装置**（Dust_Remove）。
   - **设备类型班次综合投运率**：累加该类型下所有单体设备的投运率，按设备条数取均值，作为各类型设备的班次综合投运率展示在主表。
   - **单设备投用率公式**：`投用率 = 投用时长 ÷ 应投用时长`，其中 `投用时长 = 应投用时长 - 故障时长`。
   - **应投用时长**：固定取班次时长 **8 小时（480 min）**，不在明细表中逐行展示，仅作注释说明。

### 2.2 操作说明

- **数据类型**：多级表头统计报表、数据下钻明细、导出日志。
- **数据源**：模拟SIS设备信号、DCS设备运行状态信号，提供 2025年7月（默认）、以及竞赛跳转用的 2026年6月/7月完整班值明细。
- **操作项说明**：
  - `报表查询筛选`：
    - **班值名称**：下拉单选。提供“发电一值”、“发电二值”、“发电三值”、“发电四值”及“全部”。
    - **日期范围**：时间范围选择器，年月日。默认当月（2025-07-01至2025-07-13），最大跨度180天。
    - **班次**：下拉单选。提供“白班”、“夜班”及“全部（为空）”。
    - **外部跳转**：支持 URL 参数 `shiftValue`（或 `teamDutyName`）、`startDate`、`endDate` 自动带入筛选（如从班值月度竞赛「明细查询」进入）。
  - `报表重置`：一键清除筛选条件，恢复默认时间段与全部班值班次。
  - `导出下载`：
    - 点击时触发二次确认模态框，告知当前导出的日期范围与数据条数。
    - 确认后，自动按模板生成 CSV 数据并通过浏览器触发下载，文件名格式为《`[开始日期]至[结束日期]燃运班值报表.csv`》（例如《20250701至20250713燃运班值报表.csv》）。
  - `表头全量排序`：
    - 点击二级明细指标表头（班值、日期、各量值/单耗/时长/跳机次数/投运率等）进行升序/降序切换。
    - 排序作用于**当前筛选条件下的全部明细行**，再分页展示；不是仅对当前页数据排序。
    - 取消排序后恢复默认：按日期升序，同日内白班优先于夜班。

  - `设备类型明细下钻`：
    - 主表「设备综合投运率」下四个类型数值（入厂采样、入炉采样、除铁装置、除尘装置）可点击。
    - 点击某一类型数值后，右侧抽屉仅加载**该设备类型**下的具体设备列表，展示设备名称、运行时长、故障时长及投用率（无状态列、无有载列）。
    - 应投用时长固定为班次 8 小时，在抽屉底部合并为一条说明文案，不重复展示。
    - 「设备综合投运率」一级表头旁有提示图标：点击投运率可查看各设备投运明细。
    - 不再按整行打开全量设备清单，也不再提供「测点明细」操作列。
  - `跳机报警记录下钻`：
    - 点击「输煤系统-卸煤段/上煤段」下的**跳机次数**数值，打开右侧抽屉。
    - 展示该班次时间范围（白班 08:00–20:00 / 夜班 20:00–次日 08:00）内对应段别的电流跳机报警记录，字段为：**序号、测点名称、报警时间、恢复时间**。
    - 次数为 0 时亦可点击，抽屉展示空状态。

### 2.3 界面默认情况
- **查询范围**：默认查询2025年7月1日至2025年7月13日的统计数据。
- **排序规则**：首先按日期升序、其次按班值/班次名称顺序返回。
- **合计行**：不展示合计行，以保持报表界面的简洁和纯粹。

## 🎨 界面与布局设计

### 3.1 视觉风格
作为**独立后台统计报表查询页**，采用项目默认主题 `antd-new` 的 **浅色中后台风格**：
- **页面背景**：`#f5f5f5` 浅灰底色，与常见 Ant Design 后台一致。
- **内容卡片**：白色底、细边框 `#f0f0f0`、轻阴影，圆角 8px。
- **主题色**：Ant Design 主色 `#1677ff`，辅以成功绿、警告橙、异常红等语义色。
- **表格**：多级表头网格线清晰（表头 `#d9d9d9`、组间 `#bfbfbf` 加粗竖线）；**一级表头左对齐**、二级表头居中；单位以空格跟在字段名后（如「卸煤量 t」「电度 kWh」），不用「/」分隔。

### 3.2 布局结构
标准后台报表查询布局（单页、无大屏装饰）：
1. **页头**：页面标题「燃运值班报表」+ 简短说明文案。
2. **筛选区**：白卡片内放置班值、日期范围、班次筛选及查询/重置/导出按钮。
3. **数据表格区**：多级表头按班值展示运行指标；点击设备类型投运率或跳机次数，分别打开类型设备明细 / 跳机报警记录抽屉。
4. **明细抽屉 / 导出确认**：浅色 Drawer、Modal，符合后台交互习惯。
