视频权限设置

用户与 Agent 围绕本原型沟通确认的事实依据；记录当前有效方案与关键决策。

当前方案

  • 原型意图：维护视频摄像头授权；支持按摄像头与按人员两种视角。
  • 使用场景：管理员按人员查询并单人调整摄像头权限。
  • 当前表达：双 Tab；按人员为扁平列表（姓名/部门/已授权数量）+ 单人调整抽屉（人员摘要 + 摄像头树），无组织树与批量多选。

事实与输入

用户确认事实

  • 在原功能上调整：区分按摄像头授权 / 按人员授权，Tab 切换。
  • 按人员：去掉组织机构树；去掉多选与批量调整；筛选为姓名/登录名、部门、岗位、角色。
  • 列表字段：序号、姓名、登录名、部门、岗位、角色、已授权摄像头数量、操作（调整权限）。
  • 调整权限抽屉：顶部仅展示姓名、部门；下方摄像头树勾选；二次确认后覆盖该用户授权。

参考资料

  • 现网「视频权限设置」截图（按摄像头树表）。
  • 「用户管理」截图（组织树 + 用户列表骨架）。

当前假设

  • 新建独立原型 video-permission；数据前端 mock + localStorage。
  • 按摄像头 Tab 可演示树表、行内授权；「添加成员」引导至行内授权。
  • 按人员侧不做真实用户新增/导出；聚焦筛选与单人授权调整。
  • 叶子节点（含无子节点的分组如「过道」）均可作为可授权摄像头 ID。

原型范围

本次呈现

  • 双 Tab：按摄像头 / 按人员。
  • 按人员：姓名/部门筛选、精简列表（含已授权数量）、单人调整抽屉、二次确认、权限持久化。
  • 按摄像头：树表、已授权用户展示、行内授权抽屉。

本次不呈现

  • 真实后端、组织同步、摄像头设备联调。
  • 完整用户 CRUD / 角色权限体系。

验收重点

  • Tab 切换正常；两端授权数据同源。
  • 按人员无组织树、无多选批量；列表展示已授权摄像头数量。
  • 调整权限抽屉仅展示姓名、部门与摄像头树；确认后该用户授权更新且列表数量回显。

设计与决策

  • 设计基底：延续管理端 Ant Design 浅色（对齐截图与项目内 coal-unload / auto-entry 后台风格）；无独立 theme 包。
  • 特有调整：顶层业务 Tab；按人员扁平列表；单人调整为「人员摘要 + 摄像头树」抽屉。
