# 视频设备管理 · 原型主规格

> 本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并简短记录会影响当前原型的重要用户决策和变更。

## 当前方案

- 原型意图：把《视频公共模块-软件需求说明书》5.1 设备管理业务域与 5.2 视频监控业务域（UR2.1 视频监控、UR2.3 视频回放）落成可运行的生产级后台界面，用于评审国标摄像头接入运维的信息架构、关键录入交互与监控回放的操作路径。
- 使用场景：视频运维人员在摄像头管理左侧维护分组 → 在右侧登记摄像头（按接入方式填写国标设备 ID / 国标通道号或网络接入信息）→ 系统派生播放地址；业务用户在视频监控页点播摄像头看实时画面，或切到视频回放按时间段复核历史画面。
- 当前表达：左侧一级菜单分「视频 / 监控」与「视频 / 设备管理」两组共两项功能；视频监控为左摄像头树 + 右视频墙的双 Tab 单页形态；摄像头管理为左分组树 + 右摄像头列表的单页形态，设备信息作为摄像头字段维护、流媒体地址由部署文件下发，**不再有国标设备、流媒体服务两个独立页面**。台账数据在浏览器 `localStorage` 内可增删改查，刷新保留，左下角可恢复演示数据；回放录像段为会话内演示数据，不落 `localStorage`。

## 事实与输入

### 用户确认事实

- 菜单共两项：视频监控；摄像头管理（含分组与设备信息）；**无独立「分组管理」「通道管理」「国标设备」「流媒体服务」菜单**。

#### 视频监控（5.2 业务域）

- 入口更名为「**视频监控**」，内含 `实时监控 / 视频回放` 两个 Tab；原「视频远程集中监控」与「视频回放查询」两个菜单都收进本页，回放查询菜单取消。
- **两个 Tab 的摄像头选择与分屏交互完全一致，均按现网界面布局，不做改动**：
    - 左侧共用同一棵分组 + 摄像头树，**不使用复选框**，一律点播式。
    - 分组行提供**批量点播**图标，点击后按当前分屏数量播放该分组（含下级）的前几路，多余的不播并提示分组总路数。
    - 摄像头行点击即点播；**正在播放的摄像头节点高亮**并带播放指示点。
    - 右侧视频区可**单击分屏选中**（选中窗口蓝色描边），再点左侧摄像头节点即在选中窗口点播；点播后选中位自动移到下一个窗口。
    - **右下角状态栏**为操作入口：实时监控左侧显示「总流量：N KB/s」、回放左侧显示选中窗口的摄像头与其当前时间；右侧为分屏切换、全屏、全部关闭。实时监控在分屏左侧另有**全局高清 / 流畅**，一次切换所有在播窗口。
    - 窗口内提供单窗口放大（双击同效）与关闭本窗口；抓图仅实时监控有，回放窗口同位置换成本窗口的播放/暂停。实时窗口悬停后可单独切**高清 / 流畅**，并悬浮提示两种模式的区别。
    - 两个 Tab 各自保留自己的点播记录、选中窗口与分屏档位；切换 Tab 不互相清空。
- **实时播放模式只在实时监控提供，回放不切清晰度**。高清为连续视频取流；流畅为图片帧，无声音，画面明显更糊。分辨率不在页面上选。流畅帧率不写死在配置里，由前端按本机 CPU 核数、大致内存、屏幕大小和当前分屏路数在 1 / 2 / 5 / 8 帧/秒里匹配；分屏变化后，已处于流畅的窗口按新路数重算帧率。
- **视频监控不提供录像下载**：工具栏无「下载」按钮，时间轴不做框选，无下载确认抽屉与下载任务浮层。取证导出由后台或其他渠道处理，不在本页承载。
- 回放**不挂载录像片段列表**，改由顶部时间筛选条件驱动：开始时间、结束时间（精确到秒）+ 今天 / 昨天 / 近3天快捷项，点「查询」后各窗口按同一时间段加载；查询后再点播的摄像头**按当前时间范围自动加载**，不必重新查询。
- 分屏：实时监控 1 / 4 / 9 / 16；**视频回放最多 4 路，只提供 1 / 4 两档**，槽位也只有 4 个。窗口按点播顺序填充，**切换布局不改变顺序**；降布局时超出的摄像头移出画面并提示，切回后自动复位。
- 回放**逐窗口独立播放，不做全窗口同步**：每个窗口各有自己的时间游标、播放/暂停状态与倍速；播放控制条、时间轴定位、倍速只作用于**当前选中的那个窗口**，其余窗口保持原有进度。
- 播放控制条左侧常驻「控制窗口 N · 摄像头名」，明确当前在调哪一路；选中窗口没有画面时控制条与倍速滑块置灰不可操作。
- **倍速播放为条形拖拽滑块**：0.5 ~ 2 倍连续可拖，步进 0.1，可停在 0.6 / 0.7 这类中间值；下方 0.5 / 1 / 1.5 / 2 只是参考刻度，点文字可快速跳到该值；拖动时在滑块上方显示当前倍速；换速只改选中窗口。
- 时间轴**跟随当前选中窗口**，只画这一路的录像段；切换选中窗口时时间轴与游标同步切到该窗口。
- 时间轴**不放常驻文字注解**，操作指引改为鼠标悬浮在进度条上时随游标浮出提示。
- 数据模型对齐「1 国标设备 : N 摄像头（通道）」；摄像头即国标通道，不再单独建通道实体。
- **取消国标设备配置与流媒体服务配置两个功能**：国标设备 ID 直接作为摄像头字段维护在摄像头数据表上，同一台设备下的多路摄像头填写相同设备 ID 即可；流媒体服务地址不在平台维护，由部署文件下发。
- 摄像头新增**接入方式**（国标 / 非国标 / 兼容），决定录入范围：国标只录国标设备 ID 与国标通道号，非国标只录通道号与网络接入信息，兼容两者都录；**新增摄像头时默认「兼容」**。
- 两类业务实体：`CameraGroup` / `Camera`，**全部含创建时间、创建人、更新时间、更新人，由系统写入且表单不可编辑**。
- 摄像头、摄像头分组**均无启用状态字段**；列表不设状态列、筛选不设状态项、表单不设启用项。
- 分组名称唯一；可多级；有子节点或已关联摄像头时禁止删除；禁止挂到自身或子孙分组。
- 列表页工具栏主按钮只写动作（「新增」「导入」），业务对象由页面标题表达；抽屉标题仍写全称（如「新增摄像头」）。
- 左侧菜单项只显示菜单名称，不带副标题说明。
- 摄像头名称**全局唯一**（不限分组），不限长度、允许空格与特殊字符，唯一性比较忽略首尾空格。
- 摄像头 SN / MAC 选填；**一经填写即需全平台唯一**，留空不参与唯一性校验。MAC 比较忽略大小写与分隔符，SN 比较忽略大小写。
- 摄像头保存校验名称、国标通道号、SN、MAC 四项唯一性；校验通过才提示保存结果并关闭抽屉。
- 厂商、摄像头种类取系统字典。
- 国标设备 ID 在摄像头表单内**可输入可下拉**：候选来自**摄像头数据表中已录入的设备 ID**（按 ID 去重并标注已关联路数），也允许直接手填新值，不再有「新建设备 / 新建流媒体」的二级抽屉。
- 摄像头 IP 保留分段录入，右侧另给一个「选已录入」下拉（候选为摄像头表中已用过的 IP），选中后带出端口、账号、密码。
- 从下拉选中已有设备 ID 时，回填国标编码前缀（中心 / 行业 / 网络）与 IP、端口、账号、密码默认值，已填内容不被覆盖。
- 国标设备 ID / 国标通道号均为 20 位；通道号全局唯一，设备 ID 允许多路摄像头重复（同一台设备）。
- 通道号：国标接入按国标通道号序号后三位自动带出、可改；非国标接入必填，按硬盘录像机实际通道号录入。
- 摄像头的 Host / Port / 账号 / 密码逐路可改；取流地址只在点播窗口展示，**表单内不做取流地址预览**。
- 摄像头排序号**选填**：留空按目标分组内末位续号（提示里直接显示将取的号），填写时仍限非负整数；分组内顺序也可在列表上拖拽调整。
- 表单分三段：业务信息（名称、分组、种类、接入方式、厂商、排序号、SN、MAC、备注）、通道信息（国标设备 ID、国标通道号、通道号）、网络接入（IP、端口、账号、密码）；国标接入时整段隐藏网络接入。
- 摄像头导入按「下载模板 → 模板填写 → 数据导入 → 导入结果」推进；**选择文件后即自动上传解析，无独立「提交」按钮**；**解析完成即保存校验通过的数据，第四步只播报结果**。
- **原型不做真实文件解析**：选中任意 `.xlsx/.xls/.csv` 后停留在抽屉展示「正在导入解析数据…」，随后按模板口径生成演示数据（默认 150 条通过 + 2 条异常，共 152 条）并走真实校验规则；每次演示使用新批次号与空闲通道序号，避免重复导入时因唯一性全部失败。
- **导入结果使用侧边抽屉**（加宽至约 1180px），不使用居中弹窗；底栏只保留「关闭」，不再有保存与重新选择文件。
- **所有表单类交互统一用侧边抽屉**（摄像头、分组）；居中弹窗只用于二次确认与监控预览。
- 导入模板列头与首行注意事项**逐字对齐《摄像头数据导入模板.xlsx》**：`*摄像头名称`、`*分组`、`*种类`、`接入方式`、`**所属国标设备ID`、`**国标通道号`、`**通道号`、`**摄像头IP`、`**端口`、`**账号`、`**密码`、`*厂商`、`SN`、`MAC`、`备注`；`*` 为必填、`**` 为按接入方式条件必填。
- 必填校验：摄像头名称、分组、种类、厂商；条件必填按接入方式分支——国标接入要 所属国标设备ID + 国标通道号，非国标接入要 通道号 + 摄像头IP + 端口 + 账号 + 密码，兼容接入两组都要。
- **接入方式选填**：模板未标 `*`，留空按「国标」处理（国标为主流接入），填写则须为 国标 / 非国标 / 兼容 三选一。
- **分组不做存在性校验**：分组名已维护则挂到对应分组，未维护则在保存时自动建为**一级分组**（排序号续到顶层末位、备注写「摄像头导入自动创建」），并在导入结果与轻提示中列出自动新建的分组名。
- 有效性校验：种类、接入方式、厂商须在字典内存在，所属国标设备 ID 与国标通道号须为 20 位数字（序号非全 0），摄像头 IP 须四段合法、端口与通道号须为数字；唯一性校验：摄像头名称、国标通道号。
- 异常原因定位到字段，文案固定为：`XX字段，必填字段为空` / `XX字段，字段无效` / `XX字段，不唯一`。
- 种类填写限「枪机 / 球机」二选一；厂商模板要求「海康 / 大华 / 华为 / 360」选其一，导入实际按平台厂商字典校验（另含宇视、天地伟业、其他）。
- 导入结果存在异常数据时，明细分两个 Tab 并在 Tab 上标数量；全部正常则只展示正常数据。
- 异常 Tab 第一列为「异常原因」；异常数据可下载为 `.xlsx`（异常原因 + 模板行号 + 原模板列）。
- **校验通过的数据在解析完成时即写入，异常数据一律不保存**；异常数据只能下载修正后重新导入，不在结果页内编辑或重试。
- 本期不含业务挂载与视频权限。

### 当前假设

- 当前操作人固定为「张运维」，用于演示审计字段写入；不在界面上展示，仅体现在列表的创建人/更新人列。
- 演示用国标编码取 `43010201`（中心）+ `49`（行业）+ `0`（网络），设备类型码 `118`、通道类型码 `132`。
- 流媒体服务地址取部署常量 `DEPLOY_MEDIA_ADDRESS`（演示值 `10.50.136.251:80`），界面不提供维护入口。
- 旧本地数据按 `migrateCamera` 迁移：接入方式按国标设备 ID 与国标通道号是否齐全推断（都有为国标、都无为非国标、只有其一为兼容），下线的设备名称与流媒体地址字段读取时丢弃。
- 取流地址派生规则（FLV / WS-FLV / HLS 路径，及按厂商生成的 RTSP 路径）为演示口径，实际以后端实现为准。
- RTSP 复制按角色决定是否带密码，本原型统一按带账号展示，未做角色区分。
- 回放录像段为演示数据：按「摄像头 + 自然日」固定种子生成连续录像与随机断档，同一路同一天结果可复现；录像保留期按 30 天，超出保留期与未来时间不产出录像。
- 需求文档写的「日期 + 开始时间 / 结束时间」在实现中合并为两个精确到秒的起止时间控件，以支持「近3天」这类跨天区间，口径已同步回 docx。
- 各回放窗口的时间游标为前端模拟推进，按各自倍速每 250ms 走一步，走到查询区间末尾该窗口自动暂停。

## 原型范围

### 本次呈现

- UR1.1 摄像头管理（含分组与设备信息）：分组树增删改 + 拖拽调整父级与排序、摄像头列表筛选与本级排序拖拽、摄像头表单（接入方式切换录入范围、20 位分段通道号控件、设备 ID 可输入可选择、IP 选已录入值并带出端口账号密码）、删除二次确认。
- UR1.1 摄像头导入：导入抽屉（步骤指引 + 导入说明 + 模板下载 + 选择文件即解析）、解析中态、同一侧边抽屉内的导入结果（统计文案、双 Tab 明细、全属性横向滚动列表、异常数据下载；通过数据解析完成即保存，底栏只有关闭）。
- 摄像头与分组审计字段在列表中的只读展示（表单内不展示）。
- UR2.1 视频监控（实时监控 Tab）：分组批量点播、摄像头点播到选中分屏、播放中节点高亮、分屏选中态、1/4/9/16 分屏、总流量状态栏、全屏与全部关闭、窗口抓图/放大/关闭、单窗口与全局的高清/流畅切换。
- UR2.3 视频回放（视频回放 Tab）：与实时监控一致的点播式选择、1/4 分屏状态栏、时间筛选条件与快捷项、逐窗口独立的播放控制与拖拽式倍速滑块、跟随选中窗口的时间轴（有无录像可视化 + 悬浮操作指引）。

### 本次不呈现

- 业务挂载、视频权限。
- 国标设备配置、流媒体服务配置两个独立功能（已取消，信息并入摄像头台账）。
- **录像下载**（本期取消）：下载确认抽屉、异步下载队列与任务浮层、下载权限位与下载操作审计、下载历史记录页。
- 中心录像与 NVR 本地录像的来源区分（时间轴单轨）。
- 回放的抓图、片段剪辑，以及从入厂记录等业务页带参跳转回放。
- 多窗口对齐到同一时间点的「同步播放」开关；回放超过 4 路。
- 前端解析 `.xlsx` 二进制（实际由后端解析；原型选择 xlsx 时按模板口径生成一批待确认数据以走通结果确认流程，`.csv` / `.txt` 走真实解析）。
- 角色权限差异（RTSP 是否带密码、流媒体只读授权）与登录态。
- 分页、导出、操作日志明细页。

## 设计基底与原型特有调整

- 采用的 `DESIGN.md`：项目当前无 `src/themes/`，设计基底沿用同业务域既有原型 `src/prototypes/video-permission/`（Ant Design 浅色后台：`#1677ff` 主色、`#001529` 深色侧边导航、6px 圆角、`#fafafa` 表头与工具区）。
- 继承方式：沿用其 CSS Variables + 前缀类名 + 自建轻量组件的做法，本原型前缀为 `vdm-`，不引入 antd 运行时与 Tailwind。
- 本原型特有调整：
    - 新增左侧深色一级菜单外壳（`video-permission` 为单页 Tab，本原型需承载监控与设备管理两组功能）。
    - 新增两类分段录入控件样式：国标 20 位五段码、IP（含端口）分段输入，均使用等宽字体与居中对齐。
    - 长表格使用 `min-width` + 横向滚动 + 表头吸顶 + 操作列吸右，不做列隐藏。
    - 视频监控页在浅色后台外壳内嵌**深色视频区**（视频墙 `#0b1220`、控制条与时间轴 `#101a2e`），画面、OSD、时间轴用深底提高对比；筛选工具栏与左树保持浅色，避免整页风格割裂。
    - 时间轴配色：录像段用主色渐变，时间游标用 `#faad14` 警示色标出「当前位置」。
    - 抽屉/弹窗底栏按钮三级：主按钮实心主色（最右）、次级按钮主色描边（`vdm-btn-ghost`）、取消一类中性动作用次要文字色的白底描边按钮。摄像头表单主按钮为「保存并预览监控」（新增/编辑后建议直接验证画面），「保存」为次级。
    - 数据密集界面的精细化处理：编号 / IP / 时间等数字统一 `tabular-nums` 纵向对齐；表头吸顶与操作列吸右带投影分层；行悬停首列加主色标记。
    - 动效克制且统一：遮罩淡入 + 抽屉右滑 + 弹窗轻微上浮（0.18~0.24s），消息提示下落进场，按钮按下位移 1px，并在 `prefers-reduced-motion` 下全部关闭。

- 导入模板的种类仅允许「枪机 / 球机」、厂商仅允许「海康 / 大华 / 华为 / 360」，与表单内种类字典（含半球机、全景机）和厂商字典范围不一致，需确认以哪一份为准。
- 导入单次条数上限、是否需要导入历史记录与原始文件回溯，需求未提及。
- 行业编码在需求中写「集成国标设备」，当前实现为继承设备且只读、不可改，需确认是否允许例外修改。
- 取流地址的 FLV / HLS 路径格式与各厂商 RTSP 路径规则需后端确认。
- 列表是否需要分页与导出，需求未提及，当前为全量滚动。
- 回放录像的实际来源（中心录像 / NVR 本地录像）与保留天数需现场确认；当前按中心单轨、保留 30 天实现。
- 回放 4 路上限按用户要求实现，实际并发解码能力与是否需要在超限时给出更强提示，需现场确认。
- UR2.1 中「摄像头台账区与视频区可拖拽调整占比」「小蓝接口慢导致展开分组为空的优化」本次未实现，需确认是否纳入。
- 实时监控的总流量为按在播路数的码流累加估算；实际应由流媒体侧上报。
