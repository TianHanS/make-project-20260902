自动入厂流程配置已确认

本文档是用户与 Agent 围绕当前原型进行方案沟通、确认和持续生成的事实依据。只维护当前有效方案，并简短记录会影响当前原型的重要用户决策和变更。主规格已确认，实现需与本文双向同步。

当前方案

  • 原型意图：重建「自动化配置」中模块类型 AER（自动入厂）的流程配置能力，供现场实施人员按设备与业务编排入厂自动化流程及子流程参数，支撑全自动无人值守。
  • 使用场景：实施人员在自动化配置卡片列表中找到 AER 模块，进行流程配置或将已有流程复制到同类型模块。
  • 当前表达：保留卡片列表骨架；AER 卡片仅提供「流程配置」「复制流程」。流程配置为右侧抽屉（左库右流）；子流程库以图标添加；「快速配置」与参数配置均为二级右侧抽屉；复制为右侧抽屉 + 二次确认抽屉。

事实与输入

用户确认事实

  • 目标用户：现场实施人员。
  • 模块类型：AER 自动入厂；卡片可用操作仅流程配置、复制流程（去掉控制设置）。
  • 不做地形 / 测距 / 测量参数（前文笔误）；不做暂存，仅直接保存；日志不在本配置中体现。
  • 子流程库固定四类：车辆识别、登记、道闸控制、现场复位；可点选加入执行列表，可重复添加、可排序、可删除。
  • 参数配置：点击执行列表中的子流程，打开二级抽屉配置；参数需有说明引导。
  • 快速配置：点击「快速配置」打开二级抽屉，列出多个预制方案（名称 + 说明），选中后确认加载子流程及参数；标记场景就绪，无需二次打开配参即可保存；允许再微调。当前 mock 含：标准自动入厂、粉煤灰固废自动入厂、卡号识别入厂、兼容识别自动登记。
  • 手动加入的子流程项标记「待确认」；点开配参并关闭后清除标记；保存时若仍有待确认则弱提示，不阻断保存。
  • 复制流程：抽屉展示源模块名；复制到同类型模块（排除自身）；二次确认；目标已有配置则覆盖更新；提示结果。
  • 设计基底：延续项目 Ant Design 后台浅色；主规格载体 HTML。

参考资料

  • 原功能截图：自动化配置卡片列表、旧版流程配置弹窗。
  • 业务配置表：自动入厂（煤/非煤）— 模块类型 AER 的子流程与字段说明（含标准自动入厂流程预制值）。

当前假设

  • 列表页筛选（模块名称 / 模块类型）、分页沿用原交互形态，用 mock 数据展示；非 AER 卡片保留「控制设置 / 流程配置」静态占位（不可用或点击提示本原型仅演示 AER），本轮验收聚焦 AER。
  • 标准场景预制序列：车辆识别 → 登记 → 道闸控制 → 现场复位（各 1 次）；参数按配置表「标准自动入厂流程」默认值；其中 reset_barrierControl 预制为 0 无。
  • 场景加载写入的子流程项视为已确认（无「待确认」标记）。
  • 登记类型变更时，相关通知项按配置表约束显隐或禁用。
  • 保存成功以 Message 提示；配置持久化用前端内存 / localStorage 模拟。
  • 鉴权、真实设备联调、后端接口、非 AER 类型完整表单不在本期。

原型范围

本次呈现

  • 自动化配置卡片列表（含 AER 与若干同类型/其他类型 mock 模块）。
  • AER：流程配置右侧抽屉（子流程库图标添加、执行列表编排、快速配置、保存）。
  • 快速配置二级抽屉（多模板选择 + 确认加载 / 覆盖确认）。
  • 子流程参数二级抽屉（含字段说明）。
  • 复制流程抽屉 + 二次确认 + 覆盖结果提示。

本次不呈现

  • 控制设置；地形 / 测距 / 测量参数；暂存草稿；日志配置页。
  • 居中 Modal 作为流程主配置容器（统一右侧抽屉）。
  • 其他模块类型的完整流程表单；平台外壳与真实后端。

验收重点

  • AER 卡片仅见「流程配置」「复制流程」。
  • 流程配置 / 快速配置 / 参数配置 / 复制确认均为右侧抽屉。
  • 子流程库用 + 图标添加；可排序 / 删除 / 重复添加；快速配置选模板加载并可直接保存。
  • 手动项有「待确认」；未确认仍可保存且有弱提示。
  • 二级抽屉可编辑参数并看到引导说明；登记类型影响通知相关项。
  • 复制到同类型其他模块，排除自身，二次确认后覆盖并提示。

字段与选项对齐业务配置表；控件旁提供说明文案，降低实施理解成本。

车辆识别 carIdentify

参数字段控件选项 / 默认说明要点
识别方式 carIdentify_method 单选 1 车牌 / 2 卡号 / 3 云驿二维码 / 4 兼容（优先二维码→卡→车牌）；标准场景默认 1 按现场已装设备选择；仅一类设备时可默认该类

登记 register

参数字段控件选项 / 默认说明要点
登记类型 register_type 单选 1 煤/非煤物资（默认）/ 2 粉煤灰固废 / 3 自动登记（先查预登记再回落）；标准场景默认 1 决定后续通知组是否适用

参数字段控件选项 / 默认说明要点

现场复位 reset

参数字段控件选项 / 默认说明要点

设计基底与用户决策

设计基底与原型特有调整

  • 采用设计基底：延续本项目 Ant Design 后台浅色（与原自动化配置截图、卸煤调度原型一致）；无独立 theme 包，在原型内用 CSS tokens 还原。
  • 关键 tokens：主色 #1677ff、布局背景 #f0f2f5、卡片白底、边框 #f0f0f0 / #d9d9d9、圆角 6–8px、控件高 32px。
  • 继承方式：严格遵循 antd 后台习惯（Modal、Drawer、Form、Select、Radio、Message、Popconfirm/Modal 确认）。
  • 本原型特有调整：
    • 流程配置为右侧宽抽屉左右分栏；子流程库用 + 图标添加，名称与说明占更多空间。
    • 「快速配置」「参数配置」「覆盖确认」均为二级右侧抽屉。
    • 「待确认」用轻量 Tag/角标，非强错误色阻断。
    • AER 卡片操作区仅两按钮，去掉控制设置。
