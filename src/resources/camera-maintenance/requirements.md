# 网络摄像头维护 · 功能与数据需求说明

> 面向国标（GB/T 28181）摄像头接入场景：国标设备、流媒体独立维护；**摄像头与国标通道合并为同一实体**；**分组与摄像头合并为同一功能页（左树右表）**，降低重复填写，避免设备 ID / 通道号概念混淆。

---

## 1. 背景与目标

### 1.1 现状问题

现网「编辑摄像头」表单常把以下内容混在一张页里手填：

- 业务信息：名称、分组、种类、排序、备注
- 网络接入：IP/端口、用户名、密码
- 国标身份：国标设备 ID、国标通道号、通道号
- 播放出口：流媒体服务器、FLV / WS-FLV / HLS / RTSP

导致运维重复录入、易抄错 20 位国标码，且难以理解「多路摄像头为何共用同一国标设备 ID」。

### 1.2 目标

1. **实体拆分**：国标设备、流媒体独立维护；**摄像头（含原通道信息）为统一台账**；分组与摄像头在同一功能页维护（左树右表）。
2. **录入简化**：网络账号与国标信息在摄像头台账一次维护；所属设备下拉带出设备级信息。
3. **概念对齐**：明确「国标设备 1 : N 摄像头（通道）」；厂商/型号走系统字典，RTSP 路径由代码按字典规则拼接。
4. **审计完整**：全部业务实体记录创建时间、创建人、更新时间、更新人。

### 1.3 关键概念（必读）

| 概念 | 说明 |
|------|------|
| 国标设备 ID（device_id） | 国标体系中一台接入主体（常见为 NVR / 接入网关 / 自注册 IPC）的固定身份，20 位 |
| 国标通道号（channel_id） | 某一路视频在国标中的身份，20 位；**真正区分画面** |
| 摄像头 | 业务与通道合并后的统一实体：名称、分组 + 国标通道号、网络账号等 |
| 流媒体服务器 | 将设备/平台流转换为 Web 可播协议（FLV/HLS 等）的中心服务，不是「另一种摄像头」 |

**关系结论：**

- 国标设备与摄像头（通道）：**关联**，且为 **1 设备 : N 摄像头**。
- 同一 NVR/接入设备下多路摄像头：**国标设备 ID 相同，国标通道号不同**。
- 不单独建「通道」实体；一路摄像头即一路国标通道。

```text
国标设备 GbDevice（一个 device_id）
  ├── 摄像头 Camera …0001（含 channel_id）
  ├── 摄像头 Camera …0002（含 channel_id）
  └── …
```

同一项目/批次下，20 位编码**前缀常相同、末段序号不同**；前缀相同是平台规划结果，不是「只能改后几位」的硬规则。国标号以设备/平台已分配值为准，系统「自动递增」仅用于自建发号或录入辅助，发号后应固定。

### 1.4 本期范围外

- 业务挂载（摄像头绑定汽车衡、入厂点等）
- 视频权限（按人/按摄像头授权）

## 2. 功能点总览

| 序号 | 功能点 | 说明 | 主要实体 |
|------|--------|------|----------|
| F1 | 摄像头管理（含分组） | **左分组树 + 右摄像头列表**；分组维护与摄像头台账同一页完成 | CameraGroup、Camera |
| F2 | 国标设备管理 | 维护 device_id 台账及设备级属性 | GbDevice |
| F3 | 流媒体服务管理 | 按环境维护媒体服务基址 | MediaServer |

**厂商 / 型号**：不设独立实体与维护页；使用**系统字典**，RTSP 路径拼写规则在**代码中按字典值写死**。

**推荐菜单结构：**

```text
视频 / 设备管理
  ├── 摄像头管理        ← 日常主入口：左分组树 + 右摄像头列表（含原通道信息）
  ├── 国标设备
  └── 流媒体服务
```

> 不再单独提供「分组管理」菜单；分组的增删改在摄像头管理页左侧树完成。

## 3. 数据实体说明

### 3.1 实体关系

```text
CameraGroup（分组树）
    └── Camera（摄像头 = 业务信息 ∪ 国标通道/网络）
            └── N:1── GbDevice（国标设备）
Camera ──N:1── MediaServer（可空，空则用环境默认）

厂商/型号：系统字典（非独立表实体）
RTSP 路径：代码按字典规则拼接（非用户手填、非独立实体）
```

### 3.2 通用审计字段（所有业务实体必含）

以下字段适用于本期全部业务实体：`CameraGroup`、`GbDevice`、`Camera`、`MediaServer`。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| createdAt | datetime | 是 | 创建时间；新增时由系统写入，不可编辑 |
| createdBy | string | 是 | 创建人（用户 ID 或登录名）；新增时由系统写入，不可编辑 |
| updatedAt | datetime | 是 | 更新时间；每次保存由系统刷新 |
| updatedBy | string | 是 | 更新人；每次保存由系统刷新 |

约束：

- 表单不提供人工录入；详情/列表可按需展示。
- 新增时：`createdAt`/`createdBy` 与 `updatedAt`/`updatedBy` 同为当前操作。
- 更新时：仅刷新 `updatedAt`/`updatedBy`，不改创建信息。

### 3.3 CameraGroup · 摄像头分组

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 主键 |
| name | string | 是 | 分组名称 |
| parentId | string | 否 | 父分组，空为根 |
| sort | number | 是 | 排序，默认 0 |
| remark | string | 否 | 备注 |
| createdAt | datetime | 是 | 创建时间（系统） |
| createdBy | string | 是 | 创建人（系统） |
| updatedAt | datetime | 是 | 更新时间（系统） |
| updatedBy | string | 是 | 更新人（系统） |

说明：**不含启用状态字段**。

约束：禁止把节点挂到自身或子孙下形成环；删除前须无子分组且无关联摄像头（或提供迁移）。

### 3.4 GbDevice · 国标设备

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 主键 |
| deviceId | string | 是 | 国标设备 ID，20 位，全局唯一 |
| name | string | 是 | 设备显示名（如「先一 NVR-1」） |
| deviceType | enum | 是 | `nvr` / `ipc` / `gateway` 等 |
| host | string | 否 | 设备级 IP（NVR 集中接入时常用） |
| port | number | 否 | 设备级端口 |
| username | string | 否 | 设备级账号（摄像头可覆盖） |
| password | string | 否 | 设备级密码（脱敏存储/展示） |
| enabled | boolean | 是 | 默认 true |
| remark | string | 否 | 备注 |
| createdAt | datetime | 是 | 创建时间（系统） |
| createdBy | string | 是 | 创建人（系统） |
| updatedAt | datetime | 是 | 更新时间（系统） |
| updatedBy | string | 是 | 更新人（系统） |

约束：

- `deviceId` 建议校验长度 20、数字字符；保存后默认锁定，变更需高权限或二次确认。
- 删除前须无下属摄像头，禁止静默级联删除。

### 3.5 Camera · 摄像头（业务 ∪ 通道合并）

一路摄像头对应一路国标通道，字段合并维护。

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 主键 |
| name | string | 是 | 摄像头名称（业务展示名） |
| groupId | string | 是 | 所属分组 |
| deviceRefId | string | 是 | 所属国标设备（关联 GbDevice，下拉） |
| channelId | string | 是 | 国标通道号，20 位，全局唯一 |
| channelNo | string/number | 否 | 逻辑通道号；默认可由国标通道号末段去前导 0 推导 |
| host | string | 条件 | 网络 IP；可选继承设备级，允许覆盖 |
| port | number | 条件 | 端口，常见默认 554 |
| username | string | 条件 | 访问账号；可继承设备级 |
| password | string | 条件 | 访问密码；脱敏存储/展示 |
| vendor | string | 否 | 厂商，**系统字典** |
| model | string | 否 | 型号，**系统字典**（可与厂商联动） |
| mediaServerId | string | 否 | 所属流媒体；**下拉选择 MediaServer**，禁止手填 IP/BaseUrl；空则用当前环境默认 |
| cameraType | enum | 是 | 枪机 / 球机 / 其他 |
| sort | number | 是 | 排序，默认 1 |
| sn | string | 否 | 设备 SN |
| mac | string | 否 | MAC |
| enabled | boolean | 是 | 默认 true |
| remark | string | 否 | 备注 |
| createdAt | datetime | 是 | 创建时间（系统） |
| createdBy | string | 是 | 创建人（系统） |
| updatedAt | datetime | 是 | 更新时间（系统） |
| updatedBy | string | 是 | 更新人（系统） |

**派生展示（不手填）：**

- 所属国标设备 ID（来自关联 GbDevice.deviceId）
- FLV / WS-FLV / HLS / RTSP（流媒体规则 + 代码内 RTSP 路径规则）

约束：

- `channelId` 全局唯一；同一 `deviceRefId` 下可有多条摄像头。
- 选择所属设备后，可自动带出设备级 host/port/账号，允许本条覆盖。
- 通道号：默认由 `channelId` 末 1～4 位有效数字推导；允许修改；与默认不一致时弱提示。
- **流媒体与国标设备同属关联下拉**：`mediaServerId` 只能从已启用的 MediaServer 台账中选择，不可在摄像头表单手填流媒体地址。
- **不存 rtspPath 字段**；按厂商/型号字典值，在代码中写死路径拼写规则生成 RTSP。
- 密码列表不展示明文；编辑回显脱敏。

### 3.6 MediaServer · 流媒体服务

| 字段 | 类型 | 必填 | 说明 |
|------|------|------|------|
| id | string | 是 | 主键 |
| name | string | 是 | 如「生产流媒体」「测试流媒体」 |
| env | enum | 是 | `prod` / `test` 等 |
| baseUrl | string | 是 | 如 `http://10.50.136.251:80` |
| enabled | boolean | 是 | 默认 true |
| isDefault | boolean | 是 | 同环境下是否默认 |
| remark | string | 否 | 备注 |
| createdAt | datetime | 是 | 创建时间（系统） |
| createdBy | string | 是 | 创建人（系统） |
| updatedAt | datetime | 是 | 更新时间（系统） |
| updatedBy | string | 是 | 更新人（系统） |

约束：同一 `env` 下至多一个 `isDefault=true`。播放地址由「摄像头 + 流媒体」规则生成，不要求运维手拼。

### 3.7 系统字典 · 厂商 / 型号（非独立业务实体）

| 字典 | 用途 |
|------|------|
| 摄像头厂商 | 下拉选项，如海康、大华等 |
| 摄像头型号 | 下拉选项；可按厂商过滤（若字典支持父子） |

实现约定：

- 不提供「厂商型号」独立 CRUD 页面与独立数据表实体（以系统字典配置为准）。
- **RTSP 路径拼写规则写在代码中**，按选中的厂商/型号（或厂商）映射模板，例如：

```text
海康系: /Streaming/Channels/{channelNo}01   // 示意，以实际约定为准
大华系: /cam/realmonitor?channel={channelNo}&subtype=0
…
```

- 运维不手填 RTSP Path；变更规则走发版，不走业务表配置。
- 系统字典若平台已自带审计字段，沿用平台能力；**不在本期业务实体清单中单独建模**。

## 4. 各功能点需求明细

### 4.1 F1 摄像头管理（含分组 · 日常主入口）

分组与摄像头合并为一个功能页，布局如下：

```text
┌────────────────┬──────────────────────────────────────────┐
│ 左侧：分组树    │ 右侧：摄像头列表 + 工具栏 / 筛选          │
│ · 全部摄像头    │ · 按当前选中分组过滤（含子分组可选）      │
│ · 分组节点…     │ · 新增 / 编辑 / 删除摄像头                │
│ · 树节点右键或  │                                          │
│   工具：增删改  │                                          │
└────────────────┴──────────────────────────────────────────┘
```

#### 4.1.1 左侧 · 分组树

| 操作 | 说明 |
|------|------|
| 树展示 | 分组名称；可显示本节点摄像头数量；支持展开/折叠 |
| 顶部「全部」 | 选中后右侧展示全部摄像头（不按分组过滤） |
| 点击节点 | 右侧列表过滤为该分组下摄像头（默认含或不含子分组：实现选定一种并写清；推荐默认仅本节点，提供「含下级」开关可选） |
| 搜索 | 按分组名称过滤树节点 |
| 新增分组 | 树工具栏或右键；父分组默认为当前选中节点（根则可空） |
| 编辑分组 | 树节点操作；字段：名称*、父分组、排序*、备注；审计只读 |
| 删除分组 | 有子节点或已关联摄像头时禁止删除，并提示先迁移 |
| 启用状态 | **无**启用/停用字段 |

校验：建议同级名称唯一；排序 ≥ 0；禁止将节点挂到自身或子孙下形成环。

#### 4.1.2 右侧 · 摄像头列表

| 列 | 说明 |
|----|------|
| 名称 | — |
| 分组 | 当前过滤上下文外仍建议展示，便于「全部」视图 |
| 种类 | 枪机/球机等 |
| 所属设备 | 设备名 |
| 国标设备 ID | 可复制 |
| 国标通道号 | 可复制 |
| 通道号 | 逻辑通道号 |
| 网络 | host:port |
| 厂商/型号 | 字典展示 |
| 排序 | — |
| 状态 | 启用/停用 |
| 更新时间 / 更新人 | 审计（创建信息可放详情） |
| 操作 | 编辑、删除、预览流（可选） |

筛选（在分组树过滤基础上叠加）：所属设备、种类、厂商、状态、关键字（名称/通道号/国标号）。  
说明：分组筛选以左侧树为主，右侧可不重复提供分组下拉筛选项（避免双入口不一致）。

**新增 / 编辑摄像头表单**

| 字段 | 必填 | 约束 |
|------|------|------|
| 摄像头名称 | 是 | **全局唯一**（不限分组）；不限长度、允许空格与特殊字符；比较时忽略首尾空格；**失焦即校验**唯一性并就地反馈 |
| 摄像头分组 | 是 | 下拉树；**新增时默认带入左侧当前选中分组**（选中「全部」时需用户自选） |
| 摄像头种类 | 是 | 枚举 |
| 所属国标设备 | 是 | 下拉；选后可带出设备级网络/账号 |
| 国标通道号 | 是 | 20 位；全局唯一；编辑默认锁定策略同设备 ID |
| 通道号 | 否 | 默认同国标通道号末段推导，可改 |
| Host / Port | 条件 | 可继承设备；本条可覆盖 |
| 用户名 / 密码 | 条件 | 可继承设备；密码脱敏 |
| 厂商 | 否 | 系统字典 |
| 型号 | 否 | 系统字典 |
| 流媒体服务器 | 否 | **下拉**（数据源=已启用 MediaServer）；选项展示名称，可附环境/BaseUrl 辅助；提供「使用环境默认」空选项；禁止手填 IP/URL |
| 排序 | 是 | 整数 ≥ 0，默认 1 |
| SN / MAC | 否 | 允许为空；**一经填写即需全平台唯一**，失焦即校验。MAC 比较忽略大小写与分隔符 |
| 启用 | 是 | 默认启用 |
| 备注 | 否 | — |
| 创建/更新审计 | — | 只读展示，系统写入 |

**只读派生区**

- 国标设备 ID（来自所属设备）
- FLV / WS-FLV / HLS / RTSP（可一键复制；RTSP path 由代码按厂商/型号规则生成）

**删除摄像头**

- 二次确认后删除本条摄像头台账

**保存与监控预览**

- 保存前校验四项唯一性：摄像头名称、国标通道号、SN、MAC（SN / MAC 允许为空，留空不校验）。
- 校验通过后提示保存结果并关闭弹窗；未通过则标红字段、保留弹窗。
- 「保存并预览监控」：先走同一套保存校验并保存成功，再直接唤起点播直播窗口加载该摄像头实时监控。
- 列表操作列提供「监控预览」：点击即打开点播窗口拉取并展示实时画面，不改动任何台账数据。
- 点播窗口支持 HTTP-FLV / WS-FLV / HLS 协议切换、重新拉流、抓图与全屏；RTSP 仅提供地址供外部播放器使用。
- 摄像头停用、国标通道号不完整、无可用流媒体服务时不进入拉流，直接说明原因。

**校验摘要**

- 所属设备、国标通道号必填且合法  
- `channelId` 全局唯一  
- 摄像头名称全局唯一；SN、MAC 填写后全平台唯一  
- 名称、排序合法  
- 流媒体若填写，须为有效的 MediaServer 主键（下拉选中项）  

#### 流媒体下拉交互（与「所属国标设备」同模式）

```text
流媒体服务器  [▼ 请选择 / 使用环境默认 ]
                ├── （空）使用环境默认
                ├── 生产流媒体 · prod · http://10.50.136.251:80
                └── 测试流媒体 · test · http://...
```

- 选项仅含 `enabled=true` 的 MediaServer。
- 选中后，只读派生区的 FLV / WS-FLV / HLS 按该服务 `baseUrl` 重算；空选项则按当前环境默认服务重算。
- 摄像头表单不出现流媒体 BaseUrl / IP 输入框。

### 4.2 F2 国标设备管理

**列表**

| 列 | 说明 |
|----|------|
| 设备名称 | — |
| 国标设备 ID | 可复制 |
| 类型 | NVR / IPC / 网关 |
| 摄像头数 | 统计下属摄像头 |
| 网络 | IP:端口（若有） |
| 状态 | 启用/停用 |

**新增 / 编辑表单**

- 字段：名称*、国标设备 ID*、类型*、Host、Port、用户名、密码、启用、备注
- 审计字段只读展示（编辑态可见创建/更新信息）
- 国标设备 ID：新增可录；编辑默认只读，变更需确认
- （可选）提供「复制上一条前缀、末段 +1」辅助，须提示与现场设备一致

**删除**

- 存在下属摄像头时禁止删除

### 4.3 F3 流媒体服务管理

**列表**

- 名称、环境、BaseUrl、是否默认、状态、更新时间/更新人、操作

**新增 / 编辑**

- 字段：名称*、环境*、BaseUrl*、是否默认、启用、备注
- 审计字段只读展示
- 设为默认时，取消同环境其他默认

**说明（给运维）**

- 流媒体用于把国标/设备流转成 Web 可播地址，不是第二种摄像头接入。
- 摄像头配置一般只需选择「用哪套流媒体」，播放 URL 自动生成。

## 5. 播放地址生成规则（建议）

输入：`Camera` + `MediaServer`（+ 账号信息）+ 代码内 RTSP 规则（按厂商/型号字典）

```text
FLV:     {media.baseUrl}/rtp/{deviceId}_{channelId}.live.flv
WS-FLV:  ws 形态同源路径
HLS:     {media.baseUrl}/rtp/{deviceId}_{channelId}/hls.m3u8
RTSP:    rtsp://{username}:{password}@{host}:{port}{rtspPathByCode(vendor, model, channelNo)}
```

- Web 播放优先走流媒体地址  
- RTSP 多为直连设备，供后端抓拍/调试；浏览器一般不直接播  
- `rtspPathByCode`：**代码写死**，不落库、不提供运维配置页

## 6. 字段归属对照（旧表单 → 新模型）

| 原「编辑摄像头」字段 | 新归属 |
|----------------------|--------|
| 摄像头名称 / 分组 / 种类 / 排序 / 备注 / SN / MAC | Camera |
| 摄像头通道（原手填 IP:端口） | 拆为 Camera.host + Camera.port；所属设备下拉 |
| 端口 / 用户名 / 密码 | Camera（可继承 GbDevice） |
| 国标设备 ID | 只读 ← 所属 GbDevice.deviceId |
| 国标通道号 | Camera.channelId |
| 通道号 | Camera.channelNo（默认可由 channelId 末段推导） |
| 流媒体服务器 | MediaServer 下拉 |
| FLV / WS-FLV / HLS / RTSP | 派生展示，不手填 |
| 厂商 / 型号 | 系统字典字段；RTSP 路径代码规则 |

「摄像头通道」与「端口」重复应消除：存 host + port，展示层可拼接。

## 7. 权限与安全（约束）

1. 密码：存储加密/脱敏；列表不展示明文；编辑回显脱敏。  
2. 国标 ID：普通运维编辑默认锁定；变更需确认或高权限。  
3. 删除设备：有下属摄像头时阻断。  
4. 播放地址含账号的 RTSP：复制时按角色决定是否带密码。  
5. 审计字段仅系统写入，前端不可篡改。  

---

## 8. 验收要点

1. 摄像头管理为左分组树 + 右摄像头列表同一页；无独立「分组管理」菜单；分组与摄像头增删改均可在该页完成。  
2. 分组无启用状态字段；树/表单均不出现启用开关。  
3. 不存在独立的「通道管理」菜单与通道实体；摄像头台账含国标通道号与网络信息。  
4. 同一 device_id 下可配置多路摄像头（多 channel_id）；列表能看出共享设备 ID。  
5. 厂商/型号来自系统字典；无厂商型号独立维护页；RTSP 路径由代码按规则生成且不可手填。  
6. 文档与实现均不包含业务挂载、视频权限。  
7. 摄像头表单中流媒体为下拉选择（同国标设备），不可手填地址；切换选项后播放派生地址随之变化；空选走环境默认。  
8. 全部业务实体均持久化并正确维护创建时间、创建人、更新时间、更新人；表单不可手改审计字段。  
9. 能独立完成：国标设备、流媒体的增删改查。
