# 汽车衡流程配置 · 消息通知默认文案

替换配置表中笼统的「{车牌号} 请等待」。未特殊说明时 LED 与广播文案相同；`启用` 默认均为是（1）。

## 计量前

| 通知项 | LED 默认 | 广播默认 |
|--------|----------|----------|
| 识别结果通知 | `{车牌号} 识别中，请等待` | `{车牌号} 识别中，请等待` |
| 允许计量通知 | `{车牌号} 请上磅计量` | `{车牌号} 请上磅` |
| 禁止计量通知 | `{车牌号} 禁止计量，请联系管理员` | `{车牌号} 禁止计量，请联系管理员` |
| 空磅检测失败通知 | `磅上有车，请确认空磅后再计量` | `磅上有车，请确认空磅` |
| 超时未上磅通知 | `{车牌号} 超时未上磅` | `{车牌号} 超时未上磅，请尽快上磅` |
| 二次校验通过通知 | `{车牌号} 校验通过，请计量` | `{车牌号} 校验通过，请保持静止` |
| 二次校验失败通知 | `{车牌号} 车辆不一致，请重试` | `{车牌号} 车辆不一致，请重试` |
| 开始校验提示 | `请熄火下车` | `请熄火下车` |
| 校验通过通知 | `车辆已熄火，开始计量` | `车辆已熄火，开始计量` |
| 校验失败通知 | `车辆长时间未熄火` | `车辆长时间未熄火` |
| 开始核验时提示 | 按判断方法：体重=`请下磅前往等待区域`；按钮=`请下磅按下开关开始计量` | 同 LED |
| 核验成功通知 | `司机已下磅，开始计量` | `司机已下磅，开始计量` |
| 核验失败通知 | `未下磅计量，请退出` | `未检测到司机下磅，请退出后重新计量` |

## 计量中

| 通知项 | LED 默认 | 广播默认 |
|--------|----------|----------|
| 称重进行中通知 | `{车牌号} 正在计量，请保持静止` | `{车牌号} 正在计量，请保持静止` |
| 称重失败通知 | `{车牌号} 计量未稳定，请重试` | `{车牌号} 计量未稳定，请重试` |
| 超量程/超载通知 | `{车牌号} 超出量程，禁止计量` | `{车牌号} 超出量程，请联系管理员` |

## 计量完成

| 通知项 | LED 默认 | 广播默认 |
|--------|----------|----------|
| 开始抓拍 | `开始图片抓拍`（默认不启用） | `开始图片抓拍`（默认不启用） |
| 抓拍成功通知 | `图片抓拍成功` | `图片抓拍成功` |
| 抓拍失败通知 | `图片抓拍失败` | `图片抓拍失败` |
| 数据上传成功通知 | `{车牌号} {重量}吨 计量完成，请下磅` | `{车牌号} 计量完成，请下磅` |
| 数据上传失败通知 | `{车牌号} 计量上传失败` | `{车牌号} 计量失败，请联系管理员` |
| 打印成功通知 | `请司机前往门岗获取磅单` | `请司机前往门岗获取磅单` |
| 打印失败通知 | `磅单打印失败，请联系管理员` | `磅单打印失败，请联系管理员` |

## 结束流程 / 启停

| 通知项 | LED 默认 | 广播默认 |
|--------|----------|----------|
| 未及时下磅通知 | `{车牌号} 请尽快下磅` | `{车牌号} 请尽快下磅` |
| 启动消息设定 | `排队过磅 有序通行` | `排队过磅 有序通行` |
| 退出/复位消息设定 | `排队过磅 有序通行` | `排队过磅 有序通行` |

## 占位符

支持：`{车牌号}` `{重量}` `{日期}` `{流水号}` `{采样位}` `{过衡位}` `{平台消息}` 等（与入厂配置一致）。
