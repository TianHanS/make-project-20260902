# 汽车衡（WBM）流程配置 · 功能需求规格

> 对齐：最新操作表单说明 + 《自动化流程配置项-2609新版》2.1/2.2/2.3/2.4  
> 落点：`src/prototypes/auto-entry-config-form/`

## 产品原则

```text
设备布局及计量要求（基础配置）→ 确认后自动匹配执行流程与参数默认值 → 流程编排微调 / 高级参数
```

## 入口

- 未配置：流程配置 → 设备布局及计量要求 → 确认 → 多 Tab
- 已配置：流程配置 → 多 Tab（流程编排 / 高级参数）；Tab 栏右侧平级入口「设备布局及计量要求」（二级抽屉，关闭后回到原抽屉）

## 设备布局及计量要求（基础配置）

- 场景：衡器类型（含可切换衡）、上磅流程
- 布局：来车方向/对向 · 道闸/外向/内向/读卡；设备不重复
- 业务：车种、下车、二次校验、抓拍、磅单及联动打印项
- **确认**：二次确认后按规则生成执行流程与默认参数，进入多 Tab
- **保存**：仅存布局/场景，不影响已保存流程与参数（hover 提示）

## 流程编排

- 左：子流程库（标题同行：计量子流程 / 设备控制复选）→ 卡片展示分类标记（计量前 / 计量中 / 计量完成 / 设备控制）+ 加入（可重复）
- 右：执行流程拖拽调序；非必选直接删除，*必选删除需二次确认；卡片左侧色条区分分类
- 统一底部「保存」（含编排参数重载）；无独立「保存流程编排」
- 不在执行流跳转高级参数；不展示流程编码

默认编排对齐 Excel 2.2（先识别后上磅含空磅+来向道闸条件；先上磅后识别无空磅/来向道闸）。

## 高级参数

- 按执行流每一步分块（同类型多次出现则多次配置）；**左侧纵向时间轴**导航
- 顶栏固定不随内容纵向滚动：仅参数 / 仅消息筛选（互斥）+「非流程参数配置」入口
- 「非流程参数配置」二级抽屉：对齐 Excel【2.4】非流程配置项（自动卸煤、异常结束放行、启动/退出计量设定、启停时段、全局设定、动态切换等；不含已删除磅号）
- Tab 名称为「高级参数配置」
- 消息通知与 AER 一致（占位符 + 发送测试）
- 新增步骤「新增待确认」
- Tab 旁提示：如需改动更多流程信息、各环节消息通知内容，可调整对应参数以达到需要的流程效果
