# 汽车衡流程配置 · 参数对照（原型范围）

对齐需求规格。消息通知归高级；跑通所需阈值随「设备布局及计量要求」确认后写入默认值，细节在高级按子流程维护。

## 设备布局及计量要求（基础配置入口）

| 分组 | 主要项 |
|------|--------|
| 场景 | 衡器类型、上磅流程 |
| 布局 | 来车/对向：道闸、车牌内外、读卡 |
| 业务 | 车种、下车、二次校验、抓拍、磅单及打印联动 |

确认后自动匹配执行流程，并加载各子流程参数默认值。

## 高级参数

按执行流程子流程实例分块；左侧纵向时间轴按完整执行序列定位。顶栏固定：「非流程参数配置」+ 仅参数/仅消息筛选。

| 分组 | 内容 |
|------|------|
| 消息通知 | 与 AER 一致：广播/LED 分通道 + 占位符 + 发送测试（见 notify-defaults.md） |
| 非流程参数 | Excel【2.4】：自动卸煤、异常结束放行、启动/退出计量设定、启停时段、全局设定、动态切换等（不含已删除磅号） |
| 上磅超时 | 超时秒、超时落闸 |
| 量程矩阵 | 本期占位 |

## 附录 A（摘录）

燃煤重/轻最小上磅 40/10 t；物资 20/5；搬倒 3；生物质 20/2；搬倒分类 25 t；煤/物资/生物质最小下磅 0.5；搬倒 0.01。
